## 与当前Skill的具体差异

现有 [对白核心](../skills/script-buyu/references/dialogue-craft.md) 已处理关系语境、称呼、接收及必要重复；[正文回读](../skills/script-buyu/references/text-review.md) 已比较删改损失、事实边界及独立意见；[故事构思](../skills/script-buyu/references/story-craft.md) 已允许人物误知、差异关注与自然省略。因此不能把其他仓库相似表述重新加成一套流程。

有价值的下一步是检验具体修订是否改善现场交流，同时保住后文条件。优先两个问题：

1. **自然化会不会偷换动作事实。** 人物页的一处例子把明确关闭录音改成遮掩手机动作；后者本身不能证明录音已经关闭。其后文也允许按揭示需要处理，故不能判整个方法必错。应在实际后文依赖录音状态时检验：能否让动作自然，又使该状态在本作需要的时点有依据。已有连续性方法可以处理，暂不新增规则。
2. **公开和私下的说法如何变化。** 称呼、解释量和说话方式可随实际听者调整；稳定称呼也可能成立。试验应保护人物原有关系，不把礼貌、昵称或一次称呼变化直接判成和解、亲密或决裂。

这两项是待测候选，不是已证明的增益。本轮不安装整套上游Skill、不追加禁词表、情绪步骤、对白密度阈值或常驻岗位。若实际稿比较没有更好，就保留现有方法和正文。
