# 作家与导演公开方法接入方案

状态：J10研究方案，供审阅；尚未接入运行时的方法选择。用户本轮明确更改的文档／图片流程另行实施。本方案不建立“名家本人代理”，不固定模仿口吻或画风，也不承诺加入名字后作品自动变好。

## 接入决策

值得补充按问题检索的公开方法。现库已有3项有来源的方法、9项内部规则及12个未核候选；已有H05与入口允许观察、诗性、非英雄叙事，不把它误称为新能力空白。优先补充来源、操作步骤和适用反例；重复原则合并，不按名家人数计覆盖。

写作组织方式、导演镜头表达、人物美术画风分别选择：采用某位导演的信息分配方法，不等于画面必须像其电影；水彩、写实、动漫或其他媒介仍从本剧决定。按问题选择少量方法，也可不用，不固定“主一辅一”配额。同层方法冲突时保留备选并按当前目标取舍，不机械平均。

建议的共同卡字段：ID、功能名称、作者／导演、来源URL与日期及正文定位、直接观点摘要、我方适配步骤、适用问题、禁用／限制、允许阶段、可改字段、验收反例、来源读取状态。所有中文步骤是本库归纳，不冒称作者逐条授课。只收短摘要和链接，不复制访谈或出版书全文。

## 五个首批方向

### W01 关系与观察叙事：补强已有H05

来源：Ursula K. Le Guin [官方本人问答](https://www.ursulakleguin.com/bvc-navigating-the-ocean-of-story-session-2-round-1)，原发2016-02-29，Q2／Q3；本轮直接读取。她反对把冲突作为唯一叙事动力，也反对把个人结尾偏好变成通用要求。自引《Steering the Craft》；不把提问者的作品例举当作者分析。

我方适配：选择本篇希望读者注意、理解或持续感受的关系；以发现、照护、等待、失去、并置等组织材料，冲突按需要保留；检查结尾与本篇表达目标的关系。静态氛围可不发生人物转变。

适用草稿中的日常、群像与观察；可调整关注点、视点、片段组织和结尾。不能因此删掉用户要求的对抗、谜底或高潮。反例：照护短篇被强塞救世主成长，或任务要求关系累积却只堆无关日常。对既有已确认故事只作检查，不擅自重构。

### W02 从对白发现人物关系

来源：Harold Pinter [2005诺奖讲稿](https://www.nobelprize.org/prizes/literature/2005/pinter/lecture/)，定位“Most of the plays…”及《The Homecoming》《Old Times》起笔段。官方页面直开403，本轮核对的是官方搜索返回的相关正文；[官方PDF入口](https://www.nobelprize.org/uploads/2018/06/pinter-lecture-e-1.pdf)供复核。直接支持从一句话／画面继续发现人物的个人经验，不是通用对白法则。

我方适配：在具体场景以一句有对象的话起稿；让对方按自身注意力回应或行动；根据互动证据完善尚未确定的关系，标清已知与猜测。已有身份、动机和事实不得推翻。

用于允许探索的草稿及已授权改写，不在Excel保真阶段启用删改。可改未锁定的开场、回应和动作，不能固定回避、敌意或停顿。反例：以含混对白遮掩作者不清楚事件；把诚实角色无依据写成隐瞒者。H06已有减少重复解释，此卡重在约束内生成场景，不重复增加“删解释”规则。

### D01 信息差与注意力组织

来源：Alfred Hitchcock本人1937年文章 [My own methods](https://www.bfi.org.uk/sight-and-sound/features/alfred-hitchcock-my-own-methods)，本轮直接读取；《Blackmail》观众知情段与《Sabotage》手、眼、刀及反应镜头段。文中《Blackmail》理想结局未按原设想拍成，不能当上映结果。

我方适配：列清观众与角色已知内容；选必须注意的既有细节；以细节和反应顺序表达意义。用于信息差、压力及心理反应，不能要求所有故事提前亮谜底。

草稿可建议信息释放结构；确认后只能在既定揭示时点内调整动作、主画面和运镜。反例：结尾才揭晓的信件在开头特写可读，即使台词没改也已改变故事，应提出变更后再确认。

### D02 生活行为与空间调度

来源：是枝裕和本人 [The Rumpus访谈](https://therumpus.net/2009/06/11/the-rumpus-interview-with-hirokazu-koreeda/)，2009-06-11，问句“What about camera angles?”及《步履不停》私人素材问答。直开失败，已读取同域搜索返回的相关完整问答。他强调多人狭小空间内的实际行动需要；“小津式中景”是采访者概括，不是他的固定规则。

我方适配：找关系中一个既有生活行为；检查人物和物件路线、谁能看到谁；安排能承载该行为的画面，删除遮挡关键信息的装饰动作。

适用家庭、同事、邻里关系，可影响场景、人物、动作、主画面和运镜；不把追逐强改慢戏，不无故添喝茶段落。反例：端茶动作遮住必须看见的递信，或模仿低机位导致人物关系更难读。

### D03 人物行动与现实条件下的类型变化

来源：奉俊昊 [BAFTA 2019编剧讲座](https://www.bafta.org/media-centre/press-releases/screenwriters-lecture-series-2019-bong-joon-ho/)，2019-12-13发布，人物与情境、不同家人的反应及类型惯例进入韩国现实的回答。本轮直开失败，核对官方搜索返回相关正文；标为Translator的内容是现场翻译。其本人明确这不是最佳通用写法。

我方适配：让不同角色面对同一具体阻碍，写各自回应；使幽默／紧张来自目标与现实条件的碰撞；检查类型变化是否仍保留本场风险和人物区别。

草稿可影响事件与行动，Excel只转译已确认内容；不随机插笑料，不替角色强换动机。反例：所有人同一种搞笑反应，或笑点抹掉本来必须成立的损失。不是默认加入社会讽刺，更不是固定视觉画风。

## 具体接入位置与执行顺序

1. 维护者将来源和卡片按现有 `data/story-methods.json` 的来源／方法结构扩展，保留直接观点与适配限制。W01用于补强H05，W02与H06明确生成／修订分工。更新验证中的固定来源计数，改为核验真实来源及引用闭合，不能简单改大数字称覆盖增加。
2. 在 `references/expert-groups.md` 与写作流程加入按问题选择的入口；导演建议在草稿阶段可参与故事表达，确认后限分镜转译。元数据不写成名人风格自动模仿器；不把候选目录升级成已验证方法库。
3. 项目内部记录“问题→方法ID→场景／镜头→具体变化或检查→限制”；不向用户成稿追加方法论文。若方法只剩名字，没有影响文本或检查，视为未使用。
4. 用三类短场景做试用：日常观察、关系对白、悬念／空间行动。相同事实约束下对比基线与方法稿，隐去名家标签；检查目标感受、信息理解、空间与人物连续性。允许原稿更合适，也允许不用任何卡。审美偏好如实记录，不量化成普遍质量保证。
5. 只有来源与字段边界清楚、试用没有改动锁定事实后，才把方案升级为运行规则。本轮已完成资料核实及可执行卡草案，未完成新增方法的真实项目效果验证，尚未启用。

停止／回退：来源只能支持采访者观点时撤回本人归属；方法改变确认剧情时暂停受影响修改；效果不合适则保留原稿并停用对应卡，不回滚其他作品、不重画已确认角色。
