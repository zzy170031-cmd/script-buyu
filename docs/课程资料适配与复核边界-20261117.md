# 课程资料适配与复核边界

本次把本地课程及配套资料的研究取舍整理为公开摘要，说明哪些内容已有方法覆盖、哪些仍需实际任务验证。只公开自写归纳，不分发课件、资产、私人故事或完整试读回执；本页也不是新的必读流程。

## 课程知识怎样进入现有方法

| 学习内容 | 可用于哪类实际问题 | 现有入口与边界 |
|---|---|---|
| 情绪、身体与声音 | 关键说法是否受当前处境影响，听者实际接到了什么 | [情境与接收](../skills/script-buyu/references/dialogue-situation-methods.md)、[场面组织](../skills/script-buyu/references/text-direction.md)已有相应方法。呼吸、重音或尾音可帮助具体表达，不让每句填写情绪项目，也不把害怕、愤怒固定成一种语速或音量。 |
| 动作前提与先后 | 结果已出现，必要条件却还没成立；转译是否弄错承托、位置或交接 | [正文回读](../skills/script-buyu/references/text-review.md)、[连续性](../skills/script-buyu/references/continuity-control.md)已有核验。先检查原场是否有闪回、并行或合理省略，不为修顺擅增情节，也不把动作写成操作清单。 |
| 运镜与光影 | 模糊说法是否导致关注对象、空间或信息揭示变化 | [当前完整提示词](../skills/script-buyu/references/storyboard-prompt-current.txt)、[光影参照](../skills/script-buyu/references/image-lighting-library.md)已有入口。确有执行歧义才澄清起止、机位或焦点；复合运动和静镜均可成立，不为看清表情提前揭密。 |
| 人物参考与多视角 | 参考承担身份、服装还是临场状态；当前是否确实缺侧背资料 | [人物形象](../skills/script-buyu/references/character-visuals.md)已有用途与状态区分。明确要求换装的结果不能直接算身份漂移；三视图不保证生成一致，不成为全员固定任务。 |
| 播读、字幕与片长 | 原话、说话者、未说完、抢话及跨镜声音是否保持 | [分镜交付](../skills/script-buyu/references/storyboard-excel.md)、[片长估算](../skills/script-buyu/references/docx-delivery.md)已有要求。字幕换行不等于发声停顿，预算不等于实测；有实际任务才核具体送读接口与输出。 |
| 分类词库、课堂参数 | 按当前画面意图查找可用词汇或操作线索 | 资料可提供选择，不按整行词项拼成无关画面。参数和工具能力绑定实际版本与入口；课程中一次结果不能保证今后生成，也不以来源数量替代成稿判断。 |

这些取舍主要澄清课程案例的适用条件，没有新增通用生成规则。诸如每镜强运镜、每句短促、固定情绪映射或固定字数换算秒数，未作为本库通则吸收；用户已经明确选择的作品风格和制作约定仍按当前任务处理，也不反向一律禁止。

## 实际研究到哪里

2026-11-17本地研读记录载：五节已下载课程均纳入自动转写及抽帧阅读，配套文档、表格、图片与音频转写有逐文件记录；随后针对关键主张回查原文、指定原帧和现行规则。此摘要依据这些记录及本轮定向复核，不把材料台账完整等同于原声逐字听校或全片连续观看。

课程中的案例能暴露可检查的歧义，但不能证明本库现稿存在同错。文字可检查意图、约束与次序；音色自然度、动态流畅、参考图稳定及精确时长仍须对应的实际输出证据。没有这些证据时保留未知，不因此阻塞普通写作。有关软件的课堂展示也未升级成本库的生产能力。

## 已有多场研究的重复检查

本轮另做了一次只给连续三场正文的模型初读，随后由另一实例比较原稿与一份局部缩减稿。作者兼统稿者知晓映射；配对读者未取得方法标签、差分和前一读者的意见，按固定顺序阅读。两名读者的职责不同，不是两次独立配对试验，且都与主控共享模型体系。

初读没有指出三场内部的事实冲突或机械问答，只对后场复述的篇幅提出轻微保留。配对意见认为两稿各有所得：原稿更多保留讲述时的表演过程，缩减稿较快进入后续相处；共有的日常活动和接收反应不能归功于缩减。统稿保留原研究稿，未继续抽稿寻求更明确的胜负。

在核对发布记录时，发现[此前研究摘要](对白承接与多场积累复核-20261114.md#同日后续三场回述比较与阶段收束)已经记录同一三场的同类取舍。前一推进计划没有接上该已发布进度；本轮因此记为已知样本的重复检查，不能称首次发现、陌生题材验证或新增指令收益，也不把前后相近意见累计成独立实验。该调度遗漏已在本地继续入口纠正。

这次比较仍由既有[删留方法](../skills/script-buyu/references/revision-choice-example.md)与[正文回读](../skills/script-buyu/references/text-review.md)覆盖。读者知道某事，不等于未在场的听者已知道；换了听者也不自动要求完整重讲。比较具体接收与连读成本即可，不据此规定复述长度、强制关系变化或追加情绪描写。
