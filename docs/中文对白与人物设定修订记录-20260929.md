# 中文对白与人物设定修订记录

2026-09-29。依据本轮既有审计及用户实施授权，合并已有的流程简化修改，并调整人物、对白、情绪与文本复核的相关说明。

## 改动

- 人物性格在原有 `description` 中清楚呈现。它提供基础认识，不新增性格字段、声音档案或逐场人格追踪；关系、经历、能力和知情等按故事需要补充。人物可以矛盾、改变主意或暂未形成明确动机。
- 对白从当下处境、所知和关注展开。移除逐句索取因果理由、每轮必须变招的倾向；闲聊、直说、长谈、沉默、诗性表达都有适用空间。打断、填充词、短句和潜台词不设配额。
- 情绪依事件、关系与积累发生，不为预设峰谷制造反应。必要行动条件和后续影响继续核对；审稿须落到具体问题，不以“没解释清心理”自动判错。
- 动作与叙述保留有用的具体感受，减少机械操作说明与重复结论；修订同时检查原有趣味、语言、节奏和关系，不能只剩信息骨架。
- 不同题材及同一作品内的感情、喜剧、行动等场面按内容处理。保留专业方法与统稿职责，常规写作不填逐场方法表；确认稿、事实依赖和交付范围仍按原有规则处理。
- 增加[中文课程与台词教学资料](../skills/script-buyu/references/writing-courses.md)，由学院资料和对白页按需进入。明确区分课程、大纲、教材目录、教学报道和我方应用判断；新资料没有自动升级为通用写作规则。
