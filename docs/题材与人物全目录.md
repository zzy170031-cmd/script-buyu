## 组合及题材导航

下列入口交叉查询核心类并按人去重，返回总数受同一个limit控制；不声称各自另有十位独立新增专家。

| 入口 | 核心类 | 选择提醒 |
| --- | --- | --- |
| 宫斗权谋 | 历史、悬疑、家庭 | 先定权力制度、关系和知情，历史细节另查；不用现代公司话术直接替代古代制度。 |
| 谍战 | 犯罪、惊悚、战争 | 区分侦查、身份隐瞒和战争背景；只选实际存在的成分，不把所有谍战改成战场戏。 |
| 末世生存 | 灾难、科幻、恐怖 | 先定灾变规则及集体生存条件；不必全部使用科幻和恐怖。 |
| 穿越 | 历史、科幻、奇幻 | 先明确时间机制与记忆权限，再选真实历史或虚构世界；旧世界知识不等于全知。 |
| 重生 | 奇幻、悬疑、爱情 | 记录上一轮记忆、现实差异和代价，是否含爱情由本剧决定；不能按标签强加复仇。 |
| 系统升级 | 仙侠玄幻、奇幻、科幻 | 数值反馈不能替代动机，奖励条件和能力上限跨场一致；选符合世界设定的基础类。 |
| 无限流 | 奇幻、悬疑、恐怖 | 关卡须有共同规则与角色累积变化，不把每关当人物重置；可无恐怖。 |
| 甜宠 | 爱情、喜剧、家庭 | 以双方自主选择和关系推进形成甜感，标签不授权固定人设或抹除伤害后果。 |
| 复仇 | 惊悚、犯罪、动作 | 这是目标/情绪路径，可用于其他基础类；结果须由能力证据与代价支撑，不强制暴力。 |
| 校园 | 青春成长、爱情、体育竞技 | 确定学校制度和年龄经验，爱情竞技按实际需要组合。 |
| 医疗 | 职场、社会现实、家庭 | 类型卡只支持叙事，医疗流程与事实须另查专业来源。 |
| 律政 | 犯罪、职场、社会现实 | 区分证据、庭审规则与人物解释，相关法域和年代须另核。 |
| 商战 | 职场、悬疑、社会现实 | 先明确行业、岗位和交易规则；劳动日常型卡不能自动替代商业机制研究。 |
| 赛博朋克 | 科幻、犯罪、社会现实 | 技术与权力须改变生活选项，霓虹视觉不能代替世界机制。 |
| 太空歌剧 | 科幻、冒险、战争 | 明确文明尺度、交通通信限制和实际有无战争，不将大背景取代人物选择。 |
| 超级英雄 | 奇幻、动作、科幻 | 力量上限、伦理和身份成本共同约束爽点；选择本剧的能力来源。 |
| 古偶仙恋 | 爱情、仙侠玄幻、历史 | 区分真实历史、架空朝代与仙界；不要同时套互斥世界规则。 |
| 民俗怪谈 | 恐怖、神话、悬疑 | 注明民俗版本及虚构改写，不把文化差异当作事实错误或怪异刻板形象。 |
| 都市 | 爱情、职场、社会现实 | 都市是环境标签，按核心冲突选择基础题材，不自动添加爱情或职场。 |
| 乡村 | 社会现实、家庭、生活治愈 | 地点和生活劳动应具体，治愈基调可选，不把乡村浪漫化。 |
| 女性成长 | 青春成长、家庭、职场 | 按年龄与真实中心问题选择路径，人物性别不限定其题材或必须结婚的终点。 |
| 群像 | 家庭、战争、社会现实 | 群像是结构入口，非独立题材人数池；明确轮换视点和各人的决定权。 |
| 多元亲密关系 | 爱情、青春成长、社会现实 | 根据具体关系与社会环境创作，身份不自动规定苦难或结局。 |
| 推理破案 | 悬疑、犯罪 | 区分谜题公平性与真实侦查程序；程序规则按背景另查。 |
| 动作冒险 | 动作、冒险 | 任务旅程与动作场面各有功能，不把所有冒险转为连续打斗。 |
| 儿童童话 | 奇幻、家庭、冒险 | 儿童是受众维度，先确认年龄与理解范围，不用家庭题材自动等同儿童适宜。 |
| 游戏电竞 | 体育竞技、冒险、战争 | 竞技、任务或战争只取本剧实际成分；游戏玩法、赛季事件和玩家材料须独立核实，不能以战争卡替代游戏机制。 |
| 机甲 | 科幻、动作、战争 | 先定机体能力驾驶限制与战斗目标，技术参数必须产生行动后果。 |
| 政治社会 | 社会现实、历史、喜剧 | 选择实际制度背景与叙事基调，不强制喜剧或现实人物；事实和虚构分开。 |
| 年代情感 | 历史、家庭、爱情 | 时代规则须作用于家庭生活和关系选择，不以服装代替历史环境。 |
| 军事 | 战争、职场、动作 | 区分战争、和平训练和职业生活，军事事实另核，不生成实操战术教程。 |
