# 对白接续、重复与旁听的有限维护

本次将四个方法条目与已有对白核心对齐，减少把一段交流逐句拆成任务的风险。基线为 `f38e19a31d71e35294a218db09b25c18a79ad1e6`，只调整两份方法文件；未增加常驻专家、逐场表格或默认必读材料。

## 具体调整

- [WM01](../skills/script-buyu/references/dialogue-methods.md)：在完整往来中看说明怎样被接收，不再要求下一轮当场回答或改变态度；当前行动所需的信息仍须够用。
- 同页 WM02：先判断已有重复的节奏、关切与人物处境，需要变化时再改变回答或指向。语义没有变化不单独构成删改理由，也不为套方法增加重复。
- [DL02](../skills/script-buyu/references/dialogue-techniques.md)：由“听见后变招”改为“听进与接续”，普通直接问答仍可成立；不预设每轮有新的障碍。
- 同页 DL12：看完整场面中旁听者的在场与后续行动；反应影响理解时才需要具体写出，不逐人分配表态或小动作。

必要说明、人物知情、物件交接、称谓与事件后果，继续按既有[对白核心](../skills/script-buyu/references/dialogue-craft.md)和[正文回读](../skills/script-buyu/references/text-review.md)核对。接续更灵活，不能掩盖读者确实无法理解的事实。

## 资料依据与范围

重新核对了[鲁煤记录的曹禺两次讲话](https://wyb.chinawriter.com.cn/Pad/content/201011/22/content19295.html)中的记录者说明、关于对白与行动、回叙和具体感受的相关段落。它支持把对白放回人物当下的行动中理解，不能据此规定每一句都必须获得即时回应。该文是历史笔记重抄，非现行学院课程标准。

重新核对了[张英访谈余华](https://www.chinawriter.com.cn/n1/2022/1125/c405057-32574066.html)中讨论《许三观卖血记》语言回旋、越剧腔调和对白叙述作用的一组问答。重复可以参与节奏组织，不必每次都增添事实。这是具体作品的经验，不能变成所有作品增加重复的理由。

四个条目的操作仍属本项目编辑推演。来源观点、措辞一致性与实际成稿效果分别判断；没有把阅读相关段落写成完成整部作品或完整课程训练。

## 本轮比较能说明什么

两名无继承上下文的写作代理，在相同委托与相同选读范围下，各写都市职场、生活流、架空古装悬疑、奇幻喜剧四个完整新场面，共八份首稿。版本材料除四处方法措辞外相同。两名独立模型读者隐藏版本标签，以相反顺序完整回读八稿；正文与完整意见保留在本地。

两位读者对候选版职场、生活流场面的互动略有偏好；悬疑场都更偏基线版的清晰度；奇幻喜剧一位略偏候选，一位认为各有得失。候选稿仍出现亲属称谓的阅读疑点；另有读者指出物件交接或名称切换的小停顿。它们没有被删去后再冒充首稿成绩。

这些意见支持逐场保留得失，不支持候选普遍更优。每版只有一个作者实例，四项同时改变，作者风格、生成差异和共同模型影响无法排除，不能分别归因到某一条，也不能外推到长篇、多场关系积累、真人读演或平台表现。本次收录定位为消除与既有核心相冲突的过强措辞，稳定的文学增益仍未证实。

八稿提供的是四种完整局部经历，不是新的四类模板。后续若出现称谓、指代或交接的具体读停，先在原场面里补清实际缺口，再看语气与后文，不因此给所有对白加回音、给所有旁听者加动作。普通问答、充分解释、安静相处和诗性回旋各按作品需要成立。

结构校验、资料哈希与路径检查只证明包的相应完整性。普通使用继续从 Skill 入口按需读取方法，不依赖本地私人试稿或研究目录。
