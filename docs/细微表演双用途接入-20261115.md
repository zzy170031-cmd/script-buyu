# 细微表演与光影的按需接入

本次基于 089c679 更新正文素材导航和分镜提示词。人物命名指导继续有效。新增 `references/micro-expression-library.md`，正文从 `text-direction.md` 的“状态、说话与接收”按需进入，分镜从当前完整提示词及 `storyboard-excel.md` 进入。主入口已有这两条路径，不重复注入32条素材，也不新增人物性格字段、固定表情表或审查配额。

## 正文取舍

现有正文规则已经支持面部、声音、身体、接收与后续行动，本轮补可选细节及视角适配。人物概述、心理叙述、意象和留白仍可使用；细微表演并非唯一的文学表达手段。原创与授权扩写仍能构思新事件，忠实改编及已定场面的表现须守住事实、决定、知情和含混。环境、情绪、动作与话语不被固定成每次相同的先后链条。

库中的“微表情”是创作用语，含短暂面部反应与细微表演，不是心理诊断或测谎工具。修正领会默认缓解、重逢默认微笑、疲惫默认听见呼名三处诱导；其他条目中的初态、对象和接收条件也从本场取得。按需要选读、改写或不用，不以使用条数衡量质量。

## 当前分镜提示词 v0.7

这六项不全是表情库改动，各自的作用如下：

1. 区分故事与交付约定、可选择的创作手段，允许相容的细节补足，避免未逐字写明的表演都被当成剧情改动。
2. 在动作描述后接入可选细微表演；承接正文已成立的反应、含混与不回应。表情过程、关键时刻和观看安排仍分别落入既有列。
3. 需要读清的细节才安排相应观看机会，允许含蓄、远景与不可见反应，不自动切特写。
4. 镜头运动信息按实际移动填写，固定镜头说明构图即可。
5. 动态章节标题与已有按需原则一致，静止同样有效。
6. 保真回查聚焦事实、决定、知情、设计及原话对应；相容细节不要求逐字来源，重大变化不因叫作表情而获得许可。

保持八部分、七列分镜与两表Excel接口、对白旁白保真、人物身份连续性、负面提示词实际局部加粗红字要求。最早提示词仍只归档；当前执行入口为 `storyboard-prompt-current.txt`，本次就地替换，不保留第二个并行执行版本。

## 来源与证据边界

具体来源及采纳范围见库尾部。Paul Ekman Group公开FACS介绍仅支持可见面部动作的描述层；Open University《Start writing fiction》1.4节并列人物概述、外貌、习惯动作和场景发言，并要求比较一致性。第三方GitHub素材用于观察分类与表达取舍，不照搬逐字套用、固定时长、AU性能主张或用户专属偏好。以上都不证明本库32条能稳定提高中文或视频生成质量。

J5已完成方案质询，采用定点修订与本地文字检视。原研究的十例是作者自查；其中门外静候新增注意门内、学生听建议新增作业两处缺乏原输入支持，保留研究原件并另写纠正稿，不把原十例称作全部通过。

本轮六组微型正文对照覆盖古装重逢、科幻隔音交流、第一人称家庭疼痛、职场含混、动漫夸张与校园接话；原样保留也是合格结果。它们由同一执行者构造并修改，再由独立代理阅读，属于编辑边界检视，非真实用户稿件、受控Skill效果实验或32题材长篇回归。私人/工作试稿不进入公共Skill。实际图像、视频、XLSX呈现及接收人WorkBuddy运行不在本次证据范围。

## 用户追加的光影接入

在微表情候选尚未发布时，用户追加光影研究。将20个自写光影选项置于 `image-lighting-library.md`，人物完整提示词从 `character-visuals.md` 进入，分镜从当前完整提示词的主画面段进入。沿用当前v0.7的微表情修订后增量加入，没有用研究线程旧整稿覆盖。正文不因此加载灯光套餐或改成摄影说明。

光影用于具体的光源、方向、软硬、明暗、光色和材质关系；不固定灯数、色温、光比、轮廓光或每图项目数。参考照明与角色身份分开，同场换机位依场景中的光源承接；允许阴天、平缓、剪影和既定非写实。需要读清的表演获得观看条件，有意隐藏则仍隐藏，观众看清不自动成为人物知情。

维护者核读GitHub固定版本：Nanoleava的入口136行与visual-mechanisms全文；skillatlas的154–283、366–398、570–592行；Higgsfield的1665–1696、1846–1888行。ARRI官方公开手册只核第5–17页相关文字，软硬/主补光/分离及反射概念，不宣称审完全部图例。未采用固定情绪映射、平台参数、生产流程和通用排除flat lighting。精确来源链接在库内。源资料只作证据，不执行第三方脚本，不上传原库或手册。

六种光影文字情境覆盖参考转夜景、同窗反打、柔光高反差、剪影隐藏、干燥二维场景和移灯后的阴影变化。仅核文字相容与路由，不是实际生图试验。新增范围须重新封定相关文件并纳入发布核验，微表情J5本身不代表光影已审。
