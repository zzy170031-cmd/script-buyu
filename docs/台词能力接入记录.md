## 三轮结论的具体处置

- 复用现有整剧基准、唯一统稿、场景状态与确认流程。每场按实际缺陷选择资料，不给每句分配作者，不要求全员参加。
- 保留平常话、陪伴、长句、诗性与直说；四类试读原本可选，继续按缺陷取用。删句比较只作诊断，不把“不推进事件”当删除依据。
- 用词、句式、重音、称谓、意象、回扣、幽默和行为均提供正向操作；不靠增加禁令代替创作。
- 将“必须分场”修正为责任、关系状态须承接。同场可以认责并有限靠近，拥抱不等于免除责任。
- 区分暂时策略、对不同对象的表达与长期变化；一次承诺或宣言不证明成长。变更说话者或发生时点即使字面相同，也需查语义与依赖。
- 科幻通信例保留实际单程延迟及听取、重听、录制的额外时间；全类型规则不从该例锁定科幻。
- 用户反馈仍平淡时，记录目标尚未满足，以代表段有界试修，不以结构检查通过反驳审美反馈。
- 已确认对白按源版本、发生位置、说话者/声道、有序原文范围对应Excel行；原稿有意重复分别保留，不能全局字符串去重。
- 独立对白查询CLI和新JSON索引暂不实施；出现实际检索困难再决定。审查发言、私人历史剧本、20问表不作为运行依赖复制。

DOCX继续保留人物提示词、不嵌图；文外少量示例确认本剧视觉方向，双确认后批量人物图进入两表Excel。不增加输出列、第三张表或一套新确认。
