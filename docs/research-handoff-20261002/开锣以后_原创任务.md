# 《开锣以后》完整故事任务

请依据当前script-buyu，写一个完整中文剧本。《开锣以后》发生在架空古代小城，一个小戏班准备在茶楼演出。开场锣已经响过，暂管工钱的账房仍未回来；装钱的小木匣在柜上，里面少了大半。班里人等着这笔钱，前厅客人等着看戏，后场准备也没有停下。

写市井生活中的悬疑，可以有喜剧；各场表达随正在发生的事变化。人物因各自处境关心不同问题，观众能理解他们为什么在此时谈这些事，也能感到戏班和茶楼里的日常关系。严肃、安静、含混、长话和笑谈均按实际场面安排。人物去向和少钱的主要问题在本故事中有可理解的结果。

具体人物、彼此关系、账房去向、少钱原因及结局由作者决定。先形成简洁人物基础，写出主要人物是什么性格、如何与他人相处及与当前事情的联系；这些是创作基础，人物仍会受当下事件影响。背景为虚构小城，不需要套用某一真实朝代的制度或真实游戏机制。
