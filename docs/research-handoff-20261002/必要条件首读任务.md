# 必要条件完整首读

请独立检查本批原创任务、作者人物与故事基础及完整首稿三场。结合现行continuity-control和continuity-evaluation支持，判断读者理解核心事件、人物行动和结局所需的条件是否成立。没有提供旧稿、主代理疑点或另一阅读者意见。

这是一座虚构小城和虚构戏班，无需套用真实朝代或游戏规则。按文本已定的关系、钱物、人物去向、知情与行动，指出确切冲突、缺失的必要条件或无法完成的阅读任务；引用具体位置并结合相邻场面。判断以实际故事为准，不用“应当再解释一次”代替冲突证据。

昵称、亲近称呼、人物猜错、改变主意、画外发生的普通事情均可能成立。实际关系冲突也要如实提出。若补充只是更便于辨认，记录为可选；若修改会揭谜过早、改变责任或抹掉人物分歧，说明代价。同时指出已成立、应保留的关键交流与信息安排。

保留首次阅读发现，允许零必修或无法判断，不向其他代理索取答案，不查前批历史，不改正文。逐文件全文读、避免截断并报告实际读取范围；归还shell后离线提交最终完整意见。这是普通独立条件复核，不是正式J审计，也不证明全题材稳定。
