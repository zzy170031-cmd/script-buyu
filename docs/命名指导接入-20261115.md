# 作品名与章集名的按需指导

本轮补充 `references/story-naming.md`，由 story-craft、workflow 和 text-review 接入。标题字段、编号及导出接口不变；不增加常驻命名岗位、固定候选数量、字数、修辞或评分表。

用户反馈书名、剧名和章节名机械。当前核查显示，既有规范对命名的具体说明主要在发布适配和交付格式；这支持补充专门指导，但不能证明所有标题都有问题，也不能建立单一根因。原标题、章节摘要与制作标签用途可能不同；直述、长标题、编号、统一回目与有意重复均可成立。

指导支持随正文复核名称，保护已锁定名称与揭示顺序。作品正式名称不直接套用短视频封面文字的习惯。标题应有正文依据；只能读到部分正文时，整书候选仍需全稿核对。

资料限于两篇作者访谈中的命名问答，入口见参考页；它们只说明可以在创作中调整名称，不证明固定起名时点更好。

本轮维护验证使用六种题材的真实首章、已有目录和登记梗概，同输入分别调用基线与候选 Skill，再对首章题名作匿名比较。私人正文、逐篇题名与原始审读留在本地，不随仓库发布。首章测试不能证明全书命名合适，模型比较不能冒充真人喜好或流量结果；指导作为按需参考，不以有限测试宣称普遍收益。

实际结果：五组选择保留同一原题，剩余一组产生不同候选。未参与命名的模型审读者报告已读完六首章，对该组有限偏向候选版，亦指出其可能引出的不同期待。实际有差异的比较只有一组；同模型、单次产出与少量样本限制因果归因。读取完整性未独立核验工具轨迹。原稿未被覆盖，未验证整书正式定名、平台表现或长期稳定收益。
