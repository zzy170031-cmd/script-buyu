# 三例文本修订

## A 城市轻喜剧

### A1

清晨，收摊。

小满：三十七块，净剩的！
阿迟：先别揣，我要听它响。

小满把硬币倒进铁碗。

阿迟：好听。再来一次！
小满（笑）：还来？包子都要凉了。

两人笑着把碗推到一边。

取舍：保留原稿“听钱响”的小小庆祝，只调整末句接话和停顿。两人的高兴已经能从往来中读出，无需增加试探、创伤或金句。A2仍是第二天照常开摊，按原计划请邻居吃包子，说起昨天第一次赚到钱。

## B 悬疑单元剧

### S2

走廊里，方砚站在门边。

门的方向传来两下响声。方砚以为这是答复，向后退了一步。

隔音室里，赵乔折起一张便签，放入口袋。

取舍：分段明确走廊与隔音室两个空间，把“答复”保留为方砚的判断。赵乔没有听见走廊动静或作出回应的新增动作，也未补通信设备。此处不指明声源；水管的揭示仍留在S4，便签上的医生姓名仍留在S5。

## C 运河经营故事

### T1

林芍看着天色。

主管：船能撑住，先把这二十袋装上吧。
林芍：装上了，今天也出不了闸。
主管：可那边还等着粮。二十袋送过去，总能让人少饿一阵。
林芍：我也想今天就送到。可许可明天才来，闸又不能夜过。先装上，也只能停在这里。

她把装船单划去。

林芍：今天这趟取消。

取舍：主管以等粮者的眼前需要劝说，林芍回应同一需要，并指出先装船不能解决许可与通行时段的限制。主管仍只提建议，取消当日运粮仍由林芍决定。本例采用用户给定的原创制度作连续性依据；未调用现实河运史、法律或游戏规则，也未声称有真人专家参与。

T2涉及的问题，仅定位，不改正文：

- “看着还没到的许可”：许可仍在另一岸、次日才到，主管当晚无法直接看着这份实体许可。句中观察对象与物件位置不合。
- “在记录上写下二十袋已过闸”：记录内容不等于实际运粮事实。若写的是实情，需要解释在许可未到、当日已取消运粮的条件下，谁作出新决定、谁执行，以及何时过闸；若指当夜实际过闸，还与不能夜行冲突。若是虚报，则需在后续授权修订中明确其作为虚假记录的性质与依据，不能由本次润色擅自替用户选定。
- “林芍听到这个消息，照旧关店回家”：她究竟听到实际过闸、账面登记还是虚报，目前不清楚。“照旧”也未交代她如何理解和处理这条与刚才决定冲突的消息，不能据此断言她已同意、默许或改变立场。

以上问题使T1至T2的连续性仍待解决；本次只交付T1局部修订。
