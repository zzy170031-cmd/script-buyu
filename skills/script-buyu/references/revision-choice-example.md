# 一句试删：信息与关系动作的取舍

本页是自足的方法摘要，供有删留疑问时比较；不含完整试写，不是默认结尾，也不是全文文学效果证据。完整旧稿、单行差分和私人回执不随 Skill 分发，也不是运行本页的依赖。当前稿的修改范围仍按 [workflow](workflow.md)。

## 同一事实，说给不同人可能在做不同的事

设想一次训练确有收益，但学员在另一项活动中借训练形成的表现造成了身份误认。她已对活动工作人员澄清，后来又回到教练面前。若此刻保留一句对教练的承认，它可能重复已知事实，也可能完成向另一名听者承认用途的关系动作。

删去可能减少一遍自述，也可能丢掉此刻面对教练的回应。先前对工作人员说过，不自动替代此刻对教练说；反过来，换了听者也不保证重复有必要。比较的是当前完整互动中，哪一部分信息、人物关注和接收会损失或增加，不以更短、少解释、人物更自知来判优。这是供方法比较的概括情境，不是私人试稿的转载或一个已经验证更好的版本。

## 怎样用于本稿

有明确删留疑问时，连读争议句所在互动及必要前后文，分清它只是重复信息，还是另一次请求、承认、安慰或重申。按本篇表达与当前授权选择删、留、移位或重写；无实际收益可以保留。无需每稿双版本，不因本例禁止直说、评论、心理叙述或重复。内部分析不能直接搬成角色的方法说明。
