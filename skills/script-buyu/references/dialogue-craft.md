# 台词与故事表达

写作时先用本页短核心，遇到具体问题再查支持材料。适用于全类型、混合类型及未归类的故事；不沿用上一部剧的语气。整剧基准、当前正文和唯一统稿职责以[ensemble-writing](ensemble-writing.md)为准，确认与交付以[workflow](workflow.md)为准。

特用卡中的恐惧、格言、嘴硬关怀或双向复合不能覆盖本剧事实与人物决定；不匹配就不用。修改后的实际互动按 [文本试读](text-review.md) 比较原文和前后场，允许直说、单方责任、未答或仍然拒绝，不以更像某位作者作为验收标准。

## 先找到这部故事的说话方式

从用户意图及已有正文判断人物处境、交流对象、媒介与作品允许的语言幅度。中文默认从普通话交流和中文叙述出发，按具体关系听称呼、语气、话题承接、省略和话外音；方言、年代、行业用语依项目选，不做全员口头禅。直白、含蓄、客气、粗粝和长篇表达都可成立。题材名、作者姓名和上一部成功样本不能代替当前判断。

先进入这场事：谁在哪里、正在做什么、注意什么、听见和知道什么、身体处在什么状态。按 [场面组织](text-direction.md) 让具体处境带出用词、说话方式与实际接收，写成完整互动；承载关键意思的眼神、面部变化和语气要写在正文发生处，不能只留作者备注。普通回答、陪伴、闲谈、仪式、走神和失败沟通都可成立；无需给每句话安排目的，也无需每轮变招。动作、物件和停顿按场面需要选用，打断、错答、潜台词和金句均不设次数。

听者有自己的关注和决定权，可以拒绝、误听、不理解或普通地回答，不能只给主角递话。未发送文字、私下动作、观众独知的信息不能无因成为其知识。区分当面、语音、文字和公开发言；作品约定的消息配音不意味着角色之间语音连麦。

本项目默认每次换人发言都有明确归属，可用简短说话提示、带明确主体的发言句式或叙述转述；剧本格式自带角色名也满足。同一发言者未被打断的连续台词不用逐句重复。交流起始、人员或受话对象切换、长叙述后重新开口时，直接交代发言者及必要的受话对象，不能仅凭某人刚出现、离台词最近或最可能说话推定；换行轮数和“可以猜出”不能替代正文归属依据。用户明确选择其他文学体裁或省略方式时从其要求，不把本项目默认当作所有文学的唯一规则。人物进入、离开或隔开后，按 [场面组织](text-direction.md) 保住实际能接收的范围，不默认原先的听者仍在听。用必要的短归属保持人物可见，不为标明归属逐句堆姓名、动作或情绪标签，也不追踪无关走位。

## 从发言到接收，先辨清当前对象

构思整段交流时，从人物眼前在意、想办或回避的事选话，不只为下一条情节递信息。发言内容、正在通知/请求/安慰什么与听者实际接到什么可以不同；命令说出口不等于权威已成立，答应听懂不等于行动兑现。当前交接或共同行动要依赖这段交流时，结合既有默契看接续是否给够依据，确有缺口才补必要的协商或转述，不补固定确认流程。真问真答、已知交接条件的省略、故意回避与维系亲近的闲谈均可成立；话轮可续说、让位、中断或留给独白，不逐句标注目的或强造拒答。其分析依据及局限见 [对白与指称的研究范围](academic-methods.md#对白与指称的研究范围)，具体迁移是本库工作推导。

指称不清时先找读者当前能确定的对象：谁在说，对谁说，“他”“这里”“那件”指什么。行动者切换、多人同场、回忆返回或转述嵌套时，可在切换点重报姓名/物件，或用已有称呼、视线和交接建立锚点；同一主体的连续动作允许自然省略，不据此省掉换人发言的归属。注意转移不必添新动作，不能让装饰性攥手、皱眉替代缺失的对象；有意匿名、错认或含混按用户明确选择的叙述约定成立，不设点名间隔。

自写时点对照（弟弟、姐姐均在场）：若原意是先对弟弟说、后看姐姐，“来客看向姐姐：‘你姐交代的桌子，我已经擦过了。’”把看向姐姐的动作放早了。可写“来客对弟弟说：‘你姐交代的桌子，我已经擦过了。’说完，她才看向姐姐。”发言对象与视线对象可以不同，要按本场意图写清，不以最后看谁倒推听者。

关键意思何时抵达听者，再决定续说、截断、停顿或必要动作；手没空、噪声刚停等已有条件可以参与发言，若不影响本场表达就不用添。提示经济与误演风险要一起看，重复有时有表达作用。诗性、合唱、独白和荒诞可有自己的交谈规则，不以日常录音或遮名辨人作为通过标准。相关访谈的个人建议不成为统一节奏。

## 起草中的情境与接收

需要读者跟随现场交流或关键转向时，按 [情境与接收方法](dialogue-situation-methods.md#起草时怎样使用)构思完整往来：A 处理实际环境限制，B 处理接到什么与怎样回应，C 处理关键转向的可跟随过程，D 选择身体与话语的有效细节。已有 [场面组织](text-direction.md#状态说话与接收)继续适用，不另造一套人物状态；方法来源与本项目文字转译分开记录，引用来源不等于成稿达标。

## 正确与真实之间怎样取舍

作者负责已定事实、信息来源、必要行动条件和用户授权；人物不必正确、坦诚、通情达理，也不必准确理解自己。他可以护短、说谎、只顾眼前、答非所问，或者说出自己尚做不到的话。动机可含混、矛盾或在当场改变，作者也不必替每次反应找到唯一解释。不能自动给争执补反省、给伤害补理解、给告别补体面总结；也不能为了“像活人”强加口癖、缺点、迟疑、误会和争吵。

区分人物的矛盾与作者漏写的条件。例如，他嘴上说不在意、却反复问同一件事，可以保留；他没收到消息却准确接上远处密谈，需要修复。影响行动的伤势、资源或重大选择转变需要成立的依据；情绪起伏不必逐次解释，更不必让角色当场分析自己。依据可在上下文、行为和余波中；读者可以暂时不懂动机，但不能靠作者内部备注补齐正文缺失的必要条件。

人物可以越界或违约，故事不必立刻让他道歉、受罚或变好；记录须如实保留谁做了什么、谁没有同意及其实际影响，不能借“人性复杂”把用户锁定的拒绝改成默许。清楚的指令、真诚的道歉、成熟的商量、顺畅的快乐同样可以有生命力。判断尺度是此人与此场是否成立，不是“正确”或“不完美”的含量。

## 把材料写成有分量的场面

先构思这段经历如何发生、人物怎样参与或置身事外，再选取动作与语言写成完整场面，成稿后回读。需交代背景、规则或线索时，检查说明是否顺着人物当下的话语、动作和关注进入交流；若问句主要为索取下一条设定服务，再考虑调整回应、说明位置或删减，不以补添动作代替调整。直接问答正合处境时就保留，不必加遮掩；试探或维护原说法也可能借普通问答发生，不能只凭问答形式判成说明腔。

有人追问刚听见的词，有人继续忙自己的事，也有人只是直接答好。觉得对白太齐，既看听者是否只在递话，也看整段是否把每件小事都串成了铺垫与回收；结合人物当下关注和前后文作用取舍，原有承接成立就保留。解释多少看谁需要说、谁需要听，谈判或问讯所需的充分说明也可以自然。长谈、改口、绕开或直说都是可选办法，用后比较整场所得。判断疑似作者腔时，连读此人与听者当下在意什么、回应怎样承接；概括、格言或笑话可以服务卖弄、自夸或敷衍，不凭句式判错。若只替作者点题，反而遮掉人物眼前的计较，再作局部调整；叙述者的评论另按本作叙述约定判断。结尾由这场经历决定，不预留金句、和解或成长的固定出口；内部分析不直接搬成角色的自我说明或旁白裁决。作者核清事实与承诺范围，不要求人物当场逐条宣布边界；接纳、回避、误会、含糊或违约仍按本场人物成立。情境确需明确说明时允许直说，不能为消除说明味删掉理解必要的信息。

需要增强时，先找现有表达里值得展开的一处：某人如何看一件普通事，为什么在这里舍不得换话题，一段认真叙述怎样被另一个人接住。让词句、语序、观察和回应使这段经历可感；不只做删解释、缩短句子的减法。参看[连续示例](dialogue-examples.md)中E09的交换、E12的长句与过度压缩反例；它们的具体经历不能移植成别剧前史。

回读时问：哪一处使这个人或这段关系变得具体？删改后失去什么？某句虽准确周全，却是否抢先替人物理解、替读者总结了？也反向检查：删掉直说后是否只剩故弄玄虚，增加瑕疵后是否损害了原来的坦率与快乐。无实际收益就保留原稿。这里是本库的编辑操作，不是某位作家或导演的原话，也不是逐句填表程序。

## 增强表现力的可选资源

| 资源 | 从当前故事中取材 | 避免过写 |
|---|---|---|
| 具体用词 | 人物真正经历、付出、担忧的事情及所需专业词 | 给外行安专业知识，句句堆生活细节 |
| 句式行进 | 想法的推进、补充、转折、收回；长短随思路变化 | 批量塞语气词，统一短平狠 |
| 重音与位置 | 让关键承认、请求、拒绝落在听者能接住的位置 | 每句末尾机灵反转 |
| 称谓与礼貌 | 具体关系中的敬称、直呼、改口或给台阶 | 换称呼就当关系已修复 |
| 意象与比喻 | 人物经验、当场观察或已有意象 | 全员山河星光棋局，新比喻偷添前史 |
| 重复与变义 | 旧话被兑现、拒绝、误解或重新理解 | 满篇种子句，每集回收口号 |
| 反差与幽默 | 认真目标与处境错位，别人可以不接梗 | 降智成全笑话，笑过就抹掉损失 |
| 直说与保留 | 此人此刻想说、能说、愿意说的程度 | 人人谜语；把沉默当同意或原谅 |
| 行为与空间 | 当时的注意、身体与手头动作影响怎样说、怎样接，已有物件承接关系 | 反复攥拳递水；凭动作断言未写出的内心 |

对白、旁白和动作叙述可以采用不同语言密度。长句、诗性、直白、程式化歌唱和非写实合唱均可按本剧约定成立；不让所有角色争做名句发言人，也不按猜姓名准确率判声音失败，短命令和共同术语自然可以相近。

## 词语句式与语体的取舍

词语会改变谈论对象和关系距离。“老周还没来”换成“有关人员尚未到场”，从熟人转为类别，也更像通报：公告或故作正式可能需要，家常话里却可能突然换腔。先看本人的说法与处境，不把后者一律判错，也不以塞语气词解决所有书面感。这是本库构造的措辞对照，不是用户稿或效果实证。

句式也承载关注：长句里的补充、转折或自我修正可能让认真解释可感，断成短句也可能切掉它；长句若压住了听者此刻要接的意思，可以局部调整，不统一追求长或短。对照[长解释与分心接话](writing-choice-cases.md#长解释和没接住话各在写什么)，看同样的长谈为什么承担不同作用，不给每人固定口癖。

直接对白让读者经历此人的用词与接话；间接叙述可以归纳其所说，却不能伪称逐字原话，叙述者的判断也不自动成为人物知道的事；概述可以跨过反复问候或一段时日，代价是少了当时的声音与往来。当前恰需经历那次承认、误听或闲谈，就可展开；已足够则保持，见[展开、概述与评论](writing-choice-cases.md#展开概述和评论由谁承担)。这几种选择不排高低，也不要求各写一版。

有限参照：[Le Guin公开问答Session 1 Continued](https://www.ursulakleguin.com/bvc-navigating-the-ocean-of-story-session-1-continued)中Roccie/Benjamin、Miriam/Jacob/Robby及False Dichotomies，分别涉及信息是否必要、作者思想与人物声音、朗读及描述/行动的关系。本次只读所列问答，不是全书/课程；她的朗读、可能删减等个人建议不成为禁闲谈、强冲突或统一口语。上面的中文取舍为本库归纳。

## 从局部修辞复核到整剧

先核谁对谁说、何时说、经什么渠道，及事实、知识来源、能力、否定、条件、承诺、决定权和揭示顺序。同字换人或换时点也可能改变含义；谎言、误信不是事实。区分对不同对象的说话策略、临时情绪和长期变化；一次宣言不能证明永久成长，未写后续只能记计划。

连读完整互动、相邻承接，沿实际依赖追到受影响的伏笔、关系和回收场，最后通读完整授权范围。角色声音或回应积累有疑点时，可沿同一角色在连续场面中的发言与接收回读，同时保留对方的反应及必要处境；不把抽出的几句台词或口头禅当整个人。比较他对谁愿意解释、避开什么、哪些旧话被接住或落空，允许普通交流与稳定声口，不要求每次回读都发现变化。核重要选择归谁、配角高光有何作用、回报是否由已有经历支持。超出授权的影响只定位并提出最小修订，不能借台词优化重写全季。

沿角色回读是对 [编辑访谈及接收练习](academic-methods.md#连续创作改编与专项问题的补充范围)的文字迁移；未获真人参与时仍是Agent文字审读。角色顺口与他人实际可演接收不同，不能假称完成读演；有真实朗读条件时才可另作反馈，并区分表演/口音/重叠处理与文本问题。

按具体缺陷试读，不强制四遍返工。可把争议句临时变朴素、移除或换位置，比较损失了什么；不以更短、更燃或更含蓄自动判优。内部解释不能替代观众实际可见可听的线索。只有桌面文本检查就如实说明，不声称真人围读、配音自然或精确时长。

用户仍觉平淡而原因未明时，表达目标仍未满足。选授权范围内一个代表段有界试修，保留原稿比较；必要时澄清关键偏好。未改善就保留分歧与原稿，不用结构通过冒充艺术满意，也不无限润色全稿。

## 阶段与交付

复用[场景状态与依赖](scene-methods.md)及[观看节奏](audience-rhythm.md)，不建第二套人物设定或逐句评分。已确认故事只诊断；原话、说话人、轮次和揭示时点的修改遵守workflow，不能借增强表现力越权。用户改过的Word优先回读。转Excel按[原文发生位置映射](storyboard-excel.md)核对，不增加交付列或第三张表。

这些是写作支持与检查方法。构造例段、卡片数量和来源名气均不证明实际剧本更好；未完成的陌生样本比较、观众理解、配音与传播验证不得宣称通过。
