# 场景对白方法：24个可交叉入口

先按[台词核心](dialogue-craft.md)判断当前问题；基础操作见[DL01–DL12](dialogue-techniques.md)。下列24项是可交叉的编辑入口，不是穷尽分类或某学院标准：其中包括互动功能，以及公共场合、独白、多人等条件/形式入口。题材决定世界及类型承诺，功能说明此刻在进行什么互动。同一场可同时有关责任与关系，也可先交接再争执；不按多个命中重复改稿。

## 使用方式

先读当前人物和场景状态，判断这段互动的主要问题，默认取最匹配的入口，必要时补充形式/条件入口或其他确有作用的功能，合并处理成一份正文。每项的“完成迹象”可以是失败、悬置或关系维持，不要求成功达成目标。正常对白不必先填卡；未命中可按当前互动工作，分享见闻、赏景、招呼和仪式语言也不必硬归到冲突。

| ID／场景 | 对白需要处理的具体问题 | 可以怎样写 | 观察什么变化；何时不用 |
|---|---|---|---|
| SC01 初见与摸底 | 双方不知道对方会如何接近自己 | 从眼前共同事务开口；一句试探后，让对方用接受、转题或边界作答 | 是否确定暂时相处方式；不要一见面互报履历 |
| SC02 熟人重逢 | 熟悉程度与现状是否还相称 | 保留旧称呼或习惯的一个试探，写对方实际反应，再决定继续靠近还是改口 | 距离被确认或重估；没有既定往事就不能临时编童年回忆 |
| SC03 请求与拒绝 | 请求的范围、成本、对方的拒绝权 | 请求说到可回应的程度；拒绝可以只拒一部分；下一轮回应具体障碍 | 许可、条件或拒绝落在哪里；不得把明确拒绝写成默认同意 |
| SC04 交易与谈判 | 双方各自能让什么、不能让什么 | 围绕可交换条件推进；让一次拒绝改变下一次出价或表达策略 | 是否成交及代价；不把陪伴、道歉都写成买卖 |
| SC05 命令与交接 | 谁做什么、目标是什么、何时行动、异常怎么办 | 给当前行动必要信息；接收者确认容易误认的一处；动作回报执行结果 | 行动是否可理解；不可为了简短删掉必要坐标、对象或限制 |
| SC06 专业分歧 | 同一事实为何导出不同选择 | 让人物争论不同风险或优先项，必要时直说依据 | 决定和承担者是否明确；不编造错误机制制造争执 |
| SC07 教学与求助 | 提问者究竟卡在哪里 | 从一次具体失败讲一项规则，给对方尝试、误解或追问的空间 | 问题得到解决或更明确；不把新手当百科目录 |
| SC08 探询与隐瞒 | 谁知道什么、为何愿说或不说 | 问题对准线索；回答可以有限、含混或拒绝，必须符合知情来源 | 信息边界或可信度改变；不能让所有正常问题都答成谜语 |
| SC09 指控与辩解 | 双方是否在争同一件事 | 区分事实、责任、动机；辩解可承认一项但否认另一项；对方追问缺口 | 哪项被承认或仍悬而未决；不能靠主角气势代替证据 |
| SC10 误解与修复 | 双方把哪句话理解成了不同意思 | 给可追溯的误读点；下一轮可纠正，也可在压力下继续错开 | 误会修好、加深或被搁置；关键危险信息不准无理由拒绝澄清 |
| SC11 道歉与补偿 | 谁伤害了谁、愿承担什么 | 认具体事；允许被伤害者不接受；补偿落在可执行的承诺和后续行动 | 修复到哪一步；不以长段剖白替代承担，不逼对方当场原谅 |
| SC12 关心与照料 | 对方需要帮助还是希望保住体面 | 可直接询问，也可通过已存在的小事提供帮助；让被关心者回应或调整 | 帮助是否被接住、边界是否被尊重；不能只靠送水等固定动作 |
| SC13 暧昧与靠近 | 双方是否愿意进一步了解或接近 | 分享具体观察、问一个愿意听答案的问题，给对方推进或停下的空间 | 互相注意是否增加；无须靠羞辱、吃醋和误会证明吸引 |
| SC14 表白与定界 | 感情或关系需要说清什么 | 允许直接表达；认真写听见之后的回答和选择 | 关系承诺或边界明确；不要为了高级感故意省略必要意思 |
| SC15 玩笑与缓冲 | 谁为什么开玩笑，对方愿不愿接 | 幽默出自性格和眼前的不协调；没接住时允许停下、换话或尴尬 | 紧张被缓解还是伤人；不让每人都精准接梗，不强笑伤痛 |
| SC16 公共场合与体面 | 话说给谁听，旁人在场改变了什么 | 表面回答一人，同时考虑其他人的理解；写对方是否给台阶 | 公开说法与私下关系有无可追踪差异；不能把面子写成民族定性 |
| SC17 失败后的争责 | 损失既成，大家在保护什么 | 分清复盘、卸责、求认可；让一个具体后果打断抽象指责 | 下一次行动和责任如何分配；不让所有人轮流总结主题 |
| SC18 成功后的兑现 | 努力、承诺或旧评价得到什么回应 | 让行动先成立，再由一句确认、回扣或平常回应承接 | 观众看懂赢在哪里；不靠增加侮辱、围观喝彩制造爽感 |
| SC19 坏消息与哀伤 | 听者此刻能接收多少、需要什么 | 把必须知道的事实说清，允许重复、实际小事、哭泣或沉默 | 听者如何处理现实；不写万能安慰，不要求立刻成长 |
| SC20 告别与放手 | 哪些话此刻该说，哪些行动替它留下 | 结合既有未竟之事、承诺或普通事务；允许坦白，也允许有限告别 | 关系以何种状态结束或继续；不可无铺垫新增信物、遗愿 |
| SC21 危机中的协作 | 注意力、时间和信息如何被压缩 | 先保障命令、确认、异常；个人情绪可藏在优先救谁、拒绝放手或一句称呼里 | 行动因沟通发生什么；别在急救、逃生关键秒点插长篇表态 |
| SC22 等待与陪伴 | 谁愿留下，谁需要空间 | 平常话、共同关注、重复和沉默都可成立；小反应让关系可见 | 关系得到维持、休息或微小调整即可；不强加秘密或反转 |
| SC23 自述与独白 | 为什么在此时对自己、某人或观众说 | 明确听者、承认范围及未说内容；结构服从表达目标，可有长句 | 自我理解、公开姿态或观众认识如何变化；不伪造双人接话标准 |
| SC24 多人议事与群聊 | 谁对谁说、谁有信息和决定权 | 围绕相互影响的诉求组织发言；允许旁听者、少言者用行动改变局面 | 关注和选择有差异；不按人数平均分台词，不让每人复述相同结论 |

## 场景条件比题材标签更具体

同为 SC03“请求”，以下条件会改变说法。只记录实际影响此场的条件，不给每句建八维表。

- **关系与权利**：老友借钱、下属请假、陌生人问路，知道的事、拒绝的代价和礼貌程度不同；关系本身不决定情绪，老友未必轻松，上级未必严厉。
- **公开程度**：私聊能承认的失败，在团队频道未必肯说；但不能自动推断人物会撒谎。
- **信息分布**：双方同知、单方误知、观众先知，决定是否需要解释与误会怎样成立。
- **媒介**：面对面能观察反应；语音只能听可传达的声音；文字消息考虑发送、延迟和回复对象。未发送或删掉的输入只对本机/获准观众可见，对方不能据此接话；编辑、已读、正在输入等提示须有平台设定依据。文字聊天可以按作品约定由角色声音向观众读出，但这不代表世界内存在语音连麦，也不使未发送输入成为对方知识。
- **时间与任务**：两分钟内撤离和第二天复盘不是同一种沟通；不拿时代背景当说话速度依据。
- **进场余波**：核对前场影响是否应延续；轻松、迟发反应或装作轻松均需人物与情境支持，不要求所有人面对同一评价都受伤。
- **语言基准**：本剧是生活口语、礼制语言还是诗性表达；不能为方法突然变成现代脱口秀。
- **观众可获得的信息**：依靠表情、字幕或物件才能懂时，该线索必须真在可呈现的正文里。

## 一场戏的前后接续

只对存在转折或衔接问题的段落简记 `进入状态 → 触发事件 → 人物反应/解释 → 实际出口 → 下一场残留`；无新触发、反应未明、出口维持也成立。不要求普通动作、自言自语、分神或漫谈都有清楚策略。出口允许“仍不答应，但肯继续听”，不能擅自升级为“原谅并恢复亲密”。一次玩笑缓解气氛，也不等于前一场损失已被消化。

需要例证时读[连续对白示例](dialogue-examples.md)：认责与靠近可同场，跨场承诺须看实际兑现，明确解释也可以支持选择和行动。示例为原创演练，不代替本剧审读。
