# 场景表达与事实保护

Hope 的 21 类场景是可选导航，不是所有故事的分类上限。先按用户故事判断表达目标；没有匹配项时采用本项目自己的类型。场景标签不赋予改变人物、关系、事件或世界规则的权限。

| 主要需求 | 写作应当解决的问题 | 常见误用 |
|---|---|---|
| 热血战斗、国漫打斗、武打、仙侠动作、武器高光 | 双方目标、能力限制、空间距离、行动—应对—代价；高光由抉择或动作结果体现 | 全写招式名、固定连招、胜负无原因 |
| 群像、国漫群像 | 各人知道什么、想要什么、行动如何相互阻碍或配合 | 人人轮流说同一句口号 |
| 情绪对话、相遇 | 关系在何处变化；话语与行为是否一致；允许沉默和未说完的话 | 把对白全部改成旁白或机械禁止新对白 |
| 日常治愈 | 具体劳动、照料、等待或小习惯怎样形成情感回应 | 强加追杀、反派、反转或每场价值翻转 |
| 场域追逐 | 目标与追逐理由、逃跑路线、障碍、选择与后果 | 只换雨巷地名而复用同一追逐 |
| 奇观、东方奇观、都市奇幻 | 谁感知异常，规则是什么，奇观如何改变行动或理解 | 用形容词替代事件，擅自增加新魔法规则 |
| 军阵、攻守城、行军合围 | 兵力关系、路线、地形、情报与补给约束，决策如何形成结果 | 把战略场景写成单人追逐 |
| 朝堂权谋 | 各方资源、合法性、信息差、交换条件和承诺代价 | 一段演说让所有人无条件转向 |
| 沙盘战略、城建、战报 | 状态前后差异、导致差异的行动、人物如何理解并选择 | UI 或报表词冒充人物；只堆数值无叙事作用 |

这些是本库归纳的写作问题，不冒充原始黄金样本的逐字内容。源场景目录和原始规则见知识索引。

## 模式优先于场景标签

- 原创/授权扩写：可补足动作、情境和对白，保持已锁定事实。影响核心关系、结局或世界规则的补写按用户授权范围处理；普通局部细节无需反复征询。
- 忠实改写/纪实：保护事实和用户指定原话；如用户要求不得新增台词，则不新增。原材料缺失信息不能标成事实。
- 改题材/改场景：先区分只改表达与允许改事件。只改表达时保留动作因果及事实；若新类型与固定事实不兼容，说明冲突并提供可执行选项，不偷改事实。
- 局部修订：只改指定场次及必要的连续性影响点，避免把整季重写当成默认流程。

Hope 的固定时长档、镜头数、每秒字符系数是其产品实现约定，不导入为剧本质量标准。对白、动作、沉默分别估算时间；真正片长只能由朗读、表演或样片计时支持。
