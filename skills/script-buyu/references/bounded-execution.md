# 有界修订与继续工作

修一个按压动作时，先说清本轮要看见按钮被正确按下、原来哪只手和衣袖必须保留，以及做不到时接着做哪项独立内容。修后发现墙面还可美化，另行登记。它适用于本技能的正文、人物、分镜、排版与提交词修订；不新增自动收费生成、代理编排或用户表单。

每轮沿用项目现有问题记录，简记四件事：**当前问题、可观察验收点、必须保留的内容、未通过的退出动作**。有实际问题才记，不给普通起草加空日志。用户要求的效果不能擅自改成可选美化。

## 按影响决定怎样退出

| 情况 | 本轮执行及退出 |
|---|---|
| 不影响剧情、身份辨认、关键动作及后续衔接的小瑕疵 | 一轮最小修改＋一次定点复核。通过即关闭；未通过就保留已核可用内容、登记待修和再开条件，实际转向下一项独立工作。不能将未解决写为通过。 |
| 影响剧情、身份、关键动作或后续依赖的必修问题 | 保持未关闭，依据新证据继续解决；方法失效时换有依据的办法或列明缺件。只暂停依赖该问题的部分，继续独立内容；没有独立内容时交代具体受阻项。 |
| 额外美化或无关新问题 | 记入待处理清单，不自动并入本轮。确有必要的连带影响才随本轮修。 |

一轮只指一次有边界的修改和一次针对结果的检查。不能把反复追加补丁合称一轮；也不能以次数用完为由关闭必修项。达到本轮验收点就结束，不自行开启“还能更好”的下一轮。

## 方法无进展时换路

同一方法连续两轮没有新增有效证据或可观察改善，停止重复该方法。仅替换形容词、加更多否定词或重发同一请求不算新办法。问题严重程度不因此降低；按实际失败选择新的位置、参考、手段，或明确缺少哪项证据。小瑕疵仍按上节短修一次退出，不把两轮上限解释成默认再修一次。

局修只核受影响内容、接点和保留项；只有出现新的相关证据才扩大。不要为一句词、局部图或行高重跑全文研究、全题材评测或整轮J15。重新导出、换图、换模型、精简提交词后，复核真实改变的出口与绑定。

恢复时先读当前源、选定方案、被替代的关键指示、已试方法与结果、退出原因及再开条件。旧“已完成”、旧候选或聊天摘要不能重启已取消的解释。需要记录时直接补进 [原有问题区](continuity-record-template.md#修改传播及问题记录)，不建第二份最新状态。

外部任务回执不明，先查已有任务状态和实际产物，再核内容版本、素材身份与绑定后决定采用或继续等待；不要因等待重复提交。没有实际提交权限或费用授权时保持文字候选。登记待修后，主执行者应当实际处理下一项独立工作，不能只反复汇报同一问题。

## 结束时据实交代

写明本轮验收是否满足、哪些保留项已核、哪个必修仍开着、下一项已做到哪里。文字通过不能代替图像、运动或声音验收；只有一次成功也不证明稳定减少重试。维护对比没有同口径前后实测时，只报告本次实际轮次与退出行为，不推算节省时长。
