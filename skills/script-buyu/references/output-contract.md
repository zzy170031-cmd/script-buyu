# 剧本与脚本的交付形态

历史《铁城风云X414》及第一集Excel只说明完整度、表格格式和表达质量。其人物、题材、集数、180秒、现实／游戏比例、三渲二与镜头数量不是新项目默认值。每部作品按当前内容选择叙事和视觉方向。

## 第一阶段：剧本DOCX与文外示例

以完整故事正文为主，按需要安排标题、项目设定、一句话故事、梗概、人物、世界规则、分集逐场动作与对白。已有完整稿保留有意采用的结构；不为套目录编造设定。单句、单场修订或诊断按指定范围交付。

新成稿人物表默认五列：人物ID、姓名、人物设定、人物弧线、人物形象提示词。提示词完整可复用，对应本剧身份、外观、服装、神态、画风和构图；视觉补充不冒充真实人物事实。DOCX不嵌人物图片。无人物故事不新增角色；旧四列表可回读，有角色的新完整成稿需补齐全员提示词。

每集显示序号、集名和时长预算，每场标清场号、内外景、地点、时间及必要人物。按发生顺序交错写动作、对白、停顿及需要的声音，不能用分集概要代替正文。DOCX不放分镜表、运镜、模型参数、审计过程或维护哈希。

按 [人物形象](character-visuals.md) 在DOCX外直接展示少量代表人物示例，并标注人物ID、姓名、对应完整提示词与本剧视觉方向说明，不只给文件路径。示例数量由本剧需要决定，不要求每个人先出图。它们是中间预览，不是第三份固定交付报告，不嵌回Word。

区分两个确认对象：剧本具体内容版本及集场范围；文外示例体现的本剧视觉方向。同一条无歧义回复可同时确认。只夸样本格式或只确认其中一项，不能推断另一项批准。两项齐备后进入既有授权的批量人物图与Excel，不追加第三次许可。

全稿无角色且无身份明确的画外／语音人物时，人物示例与其确认“不适用”，不是“已批准”。不造人或生人物图；文本确认后直接交付Sheet1与空表头Sheet2。环境方向确认只在用户另有该要求时处理，不自动生成场景图。

## 第二阶段：两张工作表的Excel

按 [storyboard-excel](storyboard-excel.md) 输出一个真实XLSX：

1. Sheet1：镜号、场景、人物、动作描述、主画面描述、运镜、台词。一镜一行，内容来自获批剧本。
2. Sheet2：人物ID、人物姓名、人物形象提示词、人物参考图。完整提示词来自本剧确认设定，图片来自确认视觉方向后的外部人物资产，实际嵌入包内并逐人对应。

“全部人物”按当前获批范围解释：单集覆盖该集涉及人物，全季覆盖全季；用户明确要全剧人物库时另记录该资产范围，不将其冒充全季剧情批准。身份明确的画外／语音人物也纳入；匿名群众不擅自新增独立设计，无人物稿的Sheet2保留表头。

可复用符合最终设定的同人物示例或用户提供图片，无需重复生成；其他人物按确认方向和各自提示词批量生成。逐张原尺寸核对身份、衣着、姿态和本剧视觉一致性。有失败或缺图时保留已完成内容并明确缺口，不声称完整双表成品已交付。

## 交付前与修订

新五列纯文字提示词DOCX可严格回读；用户改过的可见提示词不能被旧JSON覆盖。旧含图稿、外部或未知格式用通用读取与视觉核对，不原地删图或丢内容。默认输出不调用旧嵌图工具。

两种正式成品仍是剧本DOCX与脚本XLSX，分阶段交付。示例图在确认阶段单独展示，内部JSON、研究、测试和审计记录不附进作品。预算不是实测片长。结构检查、正文保真、逐人图像核对和页面／表格视觉检查分别记录；无法渲染时明确限制。
