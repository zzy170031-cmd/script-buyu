# 连续性能力的行为验证

维护或实质改变 [连续性流程](continuity-control.md) 时使用，不在每次用户写一句话时重跑。软件校验、流程执行、文本语义和艺术偏好分别记录。这里的公开情境只是设计例，不能反复拿它们当陌生测试或真实用户验收。

写作、对白和导演方法的效果按 [文本试读](text-review.md) 评价读者理解、情绪、互动及场面清晰度。可以使用同一批真实前后稿，不增加配音、试拍、成片或传播实验作为完成条件。

## 一次有界验证

准备实际来稿、用户授权和必要项目文件，要求评测者使用当前Skill完成一个真实操作；不给预期答案、疑点清单或已写好的状态表。执行在独立工作目录，不能改Skill或用户原稿。有可用且获准的独立审阅者时复核；没有时明确为同Agent复查，不虚构独立席。不要为普通创作默认召集多代理。

先由出题者保存预期硬约束与正常变化，执行后比对实际产物和检查记录。输出需能追到源版本、具体场段、发现与处理；只说“会遵守规则”不算执行。测试稿不批量生图、不替用户确认、不派生正式Excel。

| 场景 | 应检出的实质问题 | 必须允许的正常情况 |
|---|---|---|
| 远场返工 | 前场借物条件变化，后面代词转交/使用依赖未登记 | 有明确许可与交接证据的转交；只改授权内文本 |
| 信息组合 | 倒叙、未发消息、限期许可组合后越权推导 | 人物误信可成立；观众知情不等于人物知情 |
| 群像与台词 | 润色把核心选择、代价转给另一人或改承诺 | 配角建议、普通交流、角色有依据的成长 |
| 混合类型 | 为爽点新增已禁能力，或删除核心后果 | 已授权转调、反转、情绪余波与合理规则例外 |
| 中断恢复 | 新Word与旧JSON/旧检查记录不同；远场项未结 | 正确识别当前来源；未变的确认范围与合格资产继续有效 |
| 全集完整 | 中段伏笔弃置、结尾改主线、缺集而称全季完成 | 用户有意开放结局、无对白剧、非线性或独立单元剧 |
| 分镜保真 | 同句两次漏一次、换说话者/声道、提前揭示，新增目标句 | 原句拆镜顺序拼回、非因果表现、动作忠实重述 |

本轮修改涉及哪类就先测哪类；长期可靠性主张需覆盖全季及跨轮真实轨迹，不能用短样本替代。评估漏检与误报：正常反转被“修平”同样失败。不同题材、输入来源及长度换样本，不固定科幻或某部黄金样本。

## 留痕与停止

保留当前Skill提交/待提交差分、输入、授权、实际输出、正文与记录对应关系、执行者/审阅者身份、发现及残余问题。结果区分“本样本满足硬约束”“未验证”“发现具体缺陷”，艺术喜好单列。没有发现不等于证明永不出错。

关键约束不满足时只修对应问题，并重测受影响路径；同一素材已公开给执行者后，复测标为已知样本。缺关键上下文则记录限制，不要求执行者猜出隐藏答案。一次执行和一次定点修复复测后，仍不确定的地方报告出来，不无限重跑到得到想要的结论。
