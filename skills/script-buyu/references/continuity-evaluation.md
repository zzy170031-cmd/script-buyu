# 连续性能力的行为验证

维护或实质改变 [连续性流程](continuity-control.md) 时使用，不在每次用户写一句话时重跑。软件校验、流程执行、文本语义和艺术偏好分别记录。这里的公开情境只是设计例，不能反复拿它们当陌生测试或真实用户验收。

写作、对白和导演方法的效果按 [文本试读](text-review.md) 评价读者理解、情绪、互动及场面清晰度。可以使用同一批真实前后稿，不增加配音、试拍、成片或传播实验作为完成条件。

## 一次有界验证

准备实际来稿、用户授权和必要项目文件，要求评测者使用当前Skill完成一个真实操作；不给预期答案、疑点清单或已写好的状态表。执行在独立工作目录，不能改Skill或用户原稿。有可用且获准的独立审阅者时复核；没有时明确为同Agent复查，不虚构独立席。不要为普通创作默认召集多代理。

先由出题者保存预期硬约束与正常变化，执行后比对实际产物和检查记录。输出需能追到源版本、具体场段、发现与处理；只说“会遵守规则”不算执行。测试稿不批量生图、不替用户确认；需要检验导出时制作明确标为维护样本的真实DOCX、两表七列XLSX及本次覆盖的提交词，不能冒充用户已确认的正式作品。

| 场景 | 应检出的实质问题 | 必须允许的正常情况 |
|---|---|---|
| 远场返工 | 前场借物条件变化，后面代词转交/使用依赖未登记 | 有明确许可与交接证据的转交；只改授权内文本 |
| 信息组合 | 倒叙、未发消息、限期许可组合后越权推导 | 人物误信可成立；观众知情不等于人物知情 |
| 群像与台词 | 润色把核心选择、代价转给另一人或改承诺 | 配角建议、普通交流、角色有依据的成长 |
| 混合类型 | 为爽点新增已禁能力，或删除核心后果 | 已授权转调、反转、情绪余波与合理规则例外 |
| 中断恢复 | 新Word与旧JSON/旧检查记录不同；远场项未结 | 正确识别当前来源；未变的确认范围与合格资产继续有效 |
| 全集完整 | 中段伏笔弃置、结尾改主线、缺集而称全季完成 | 用户有意开放结局、无对白剧、非线性或独立单元剧 |
| 分镜保真 | 同句两次漏一次、换说话者/声道、提前揭示，新增目标句 | 原句拆镜顺序拼回、非因果表现、动作忠实重述 |

本轮修改涉及哪类就先测哪类；长期可靠性主张需覆盖全季及跨轮真实轨迹，不能用短样本替代。评估漏检与误报：正常反转被“修平”同样失败。不同题材、输入来源及长度换样本，不固定科幻或某部黄金样本。

## 全题材维护覆盖

七层流程或通用连续性机制实质改变时，按当前 genre-index 的全部26个核心题材、31个组合入口及目录外输入验证。每个入口用其自身约束的具体正常例与错误例，不把一部作品换名后声称全题材通过。组合入口的成分可选，不强制全部同时上场；目录外题材如实保留未登记状态并使用现有人工导航，不造专家。日常局修只复核受影响路径。

[维护样本入口](../tests/continuity-maintenance-cases.json)保留本轮已公开的正常/错误病例；以后不再称陌生输入。横向覆盖无人、群像、多语、复唱、画外声、纪实推断、梦境及非写实表达，也核音乐、歌剧、戏曲、史诗、少儿、伦理、悲剧、魔幻和动画等题材或表现形式；纵向覆盖跨场/集、倒叙、远场依赖、同版本Word原地修改、恢复、并行合稿、参考换序。已知制作病例做定点回归，另用未把答案给执行者的新输入检验实际行为。

至少沿一个实际当前源走文字分镜、重新打开的XLSX、明确覆盖的提交词三个出口；检查逐次发生、额外事实、揭示顺序及实际媒体字节/行绑定。缺图分支不伪造图像核验；图像、运动与真实声音分开写证据。验证 [有界执行](bounded-execution.md) 是否实际停止无进展方法、保留必修未结、达到验收即结束并转向独立内容；仅复述规则不算行为。无前后实测不宣称减少多少时间或重试。

## 真实制作失效的定点回查

[接镜与动作的已知反例](../tests/continuity-mechanics-cases.json)区分剧情前提/指代、设计起点、连接结构、实际剪辑状态、中间运动和输入控制；按 [症状到验收](continuity-diagnostics.md) 选择证据，不再只核同一人物或静态首尾。它们已公开且来自同一制作链，不冒充陌生样本、独立效果实验或本轮连续回放通过。明确有依据的省略、反打和无媒体文字分支仍须允许。

## 留痕与停止

保留当前Skill提交/待提交差分、输入、授权、实际输出、正文与记录对应关系、执行者/审阅者身份、发现及残余问题。结果区分“本样本满足硬约束”“未验证”“发现具体缺陷”，艺术喜好单列。没有发现不等于证明永不出错。

关键约束不满足时只修对应问题，并重测受影响路径；同一素材已公开给执行者后，复测标为已知样本。缺关键上下文则记录限制，不要求执行者猜出隐藏答案。一次执行和一次定点修复复测后，仍不确定的地方报告出来，不无限重跑到得到想要的结论。

## 已知的导演参考反例

[维护病例](../tests/director-reference-cases.json)供本次变化涉及的定点回归：保留普通回应、二阶知情、背影留白、重复发言、参考换序和真实声音边界。它们不是新默认检查表，也不能再冒充陌生测试或生成质量证据；同一基线上单个变化、实际产物和未受污染请求的比较仍按本页执行。
