# 编剧职责与公开方法

需要补充专业基础时，读 [代表作品与电影学院资料](academic-methods.md)：具体作品段落与官方教学目标分别标注，学院不计入自然人、不提供虚构背书；只选能解决本场问题的内容。

故事统筹对稿件的一致性负责。按内容需要选择下列职责，不把全部角色机械执行一遍：

入库资格、本次代表性组合、同段唯一正文、建议取舍、主配角作用与完整性按 [选组与统稿](ensemble-writing.md) 执行。作家/导演卡是方法储备，不按人数全员组队；每项采用须能指出具体问题与可见贡献。

- 背景研究：核实影响行动的现实、历史、行业或游戏规则。
- 故事结构：按当前作品约定组织因果、观察、对照或其他结构，安排分集内容。
- 人物与关系：检查目标、对立动机、关系变化及选择代价。
- 场景编写：把梗概写成可观察的行动、回应和结果。
- 对白修订：区分人物说话策略，减少解说式重复。
- 连续性编辑：核对人物知道什么、道具与规则状态、时间线和伏笔。
- 总稿审阅：检查完整性、时长预算、用户事实和未解决问题。
- 文档整理：保留已写内容，清楚标注分集，不代替作者补剧情。

每个实际启用环节指定一个统筹职责和必要支持。真实人物/团队只作为有证据的公共方法来源；不得声称本人在场、受聘、背书、代写或授权模仿。统筹角色与现实行业名家的姓名是两回事。

先按 [场景方法与整剧一致性](scene-methods.md) 明确本场问题与整剧边界，再读取 `data/story-methods.json` 中相关卡片的适用条件、步骤、检查和限制。W01–W06、D01–D08及 [题材入口](genre-methods.md) 的G卡按需使用；每位来源只提供对应的公开方法，不代表其能力局限于一个类型。同剧不同场景可以用不同方法，统筹统一人物、规则、因果、信息与表达。`expert-candidates.json` 仅为历史候选索引：链接不等于方法证据，候选数量不等于合格专家人数。若用户特别要求10–15名有证据专家或行业统筹，必须先核实足够独立实体与具体方法；不足则如实报告，不复制映射凑数。

需要真实专家方法时，至少记录方法ID、专家/团队ID和类型、作品或实际项目证据、来源正文定位、访问时间、方法摘要、可迁移步骤、适用条件、限制和本次检查者。创作归纳与来源直接陈述分开；本库写作规则不计为真实专家。

项目内方法应用记录：方法ID → 场景或人物ID → 可修改字段 → 采用理由 → 具体改变或检查发现。没有影响正文或完成具体检查的方法，不计为使用。内部意见按workflow的优先级合并；不输出冗长会议纪要。
