# 分镜提示词精炼与结果诊断

仅在用户要求面向具体模型整理提交文本，或带生成结果来诊断时读取。完整分镜保存创作意图；提交提示词按输入模式与实际参考整理，不把七列全文和全部审核说明拼接给视频模型。本页只指导文字适配，不自动生成、上传素材、收费重试或修改已确认故事；普通剧本与七列两表交付照常进行。

独立片段、道具交接或多参考换序需要展开时，按需读[导演与素材交接](director-handoff.md)；对白/动作重叠或声音边界有预算问题时，读[预算示例](action-sound-budget.md)。沿用当前项目记录，已有材料够用就直接写，不增加默认表单或制作步骤。

## 从分镜到提交文本

先按 [表格正文与一致性约束](storyboard-excel.md#表格正文与一致性约束) 筛本镜需要的内容；精炼后保留具体身份、道具状态、连接和阶段条件，不能用“保持一致”代替。没有固定字数上限，不为变短删掉可理解的动作、表演或揭示时点。用户要逐镜复制版时，从最终回读的表格整理，仅保留适用正文与必要约束；不得夹带修订日志，也不把三列机械拼成重复的提交词。具体模型词仍以实际输入模式和参考绑定为准。

使用当前源版本和批准范围，识别本段需让观众看懂的行动、关系与信息。保留实际台词、人物归属、关键触发与揭示次序；用户已授权的故事修订另记当前版本，不从旧稿恢复。压短提示词、调整语气，或按授权改词后，把这一句和前后镜连读。原本是人物自己拿定主意，改后却像在制止对方时，先校正措辞或表演提示。不要给对方补一个原稿里没有的意图来圆这句话。

区分参考图承担身份、布局、首帧或风格中的哪项作用，沿用真实引用名称及绑定。看不到图就标明未核验；资料中的图号不能冒充已上传引用。图生视频可少重复输入图已有的外观；文生视频仍需足够的主体和空间描述。身份参考不自动锁定表情，首帧与布局参考也不自动可被文字推翻。参考冲突先处理冲突，不继续叠词。按实际核过的维度使用参考，退回候选不再当后镜依据，新图不自动胜过当前约定；换上传槽或模型后回查实际绑定，未上传记拟绑定。

单独读本镜提交词，核对画面能否辨明原分镜里的交互，参考图的用途是否与实际入画范围相符。只闻其声的人沿用本镜的画外声标注与原话。照片、倒影或屏幕里出现的人，写清在哪儿、当时能辨认到什么程度；需要辨认其可见形象时再绑定人物外貌参考。若原稿从首帧起就是空场，而所选首帧里有人，换用符合构图的可用首帧；首帧已锁定时指出冲突。

具体表演沿用当前完整提示词的细微表演要求：保留情绪如何进入注意、身体、声音和对方接收的有用细节；可与发言并行，也可停下来辨认或承受。删去冗余分解，不删成无情绪的快速问答。不同题材、人物与场面可选不同强度，不固定动作数量、时长或特写。镜头衔接根据已有空间、动作或声音联系安排；不能因画面换了，人物状态和工作就重新开始。声音跨镜延续时，按人物所在的位置和实际声源写清谁能听见、能听清多少。

先写正向、具体且与故事相容的目标；为表现尺度、紧张或气氛补的主体与道具仍须符合当前故事。负面约束及其字段按目标平台、模型和模式的实际支持处理，不将一家模型的禁用建议推广到全部模型。仅保留解决当前错误所需的排除项；Excel 中实际负面文字仍遵守既定加粗标红格式。

如果同一道具的两张静帧要分开提交，可以把后一条单独读一遍。譬如首镜里，观众看见一张借书证的正面，到翻面那一镜才读到“止借”。两镜若交给不同的美术，可沿用已定的卡形、纸色或同一张道具参考，让人认得是那张证。正面写观众此时读得到的字，背面的字留到翻面。剧本若安排观众先看清、人物后发现，就按观众当时的视角写。

把最终准备提交的这段话和实际绑定的图，再按[分镜交付前的场景复核](storyboard-excel.md#分镜交付前的场景复核)对一次。留意压缩后丢失的交接动作、声源或方向。画面与剧本冲突时，校正具体文本或替换合适的参考；在既定授权内处理，修后再看相邻镜头。提交词定稿后，沿原有源发生到镜行的映射核这份实际文本，连同精简后仍保留的原话、动作、声道和揭示顺序，终审实际交给模型的文字及对应参考绑定，通过的版本才进入已授权的制作。

## 带结果修订

先取得或定位原完整提示词、对应结果、实际模型与模式、时长及参考绑定；其余参数按诊断需要读取。执行 [有界修订](bounded-execution.md)：每轮明确问题、可观察验收、必保项和退出动作；小问题短修一次后实际推进独立工作，必修未过不关闭，同法两轮无进展就换路。记录“时间点—实际不符—期望改变”，分清观察和原因假设。无法取得视频或音轨时，只能诊断可见关键帧或文字，不能判定运动、口型和声音表演已自然；ASR只辅助核对播读内容。

先按 [症状、根因、修法与验收](continuity-diagnostics.md) 定位剧情前提/指代、镜间状态/必要过程、物理连接、中间运动或工具控制层，再选择修改位置；设计起点已错或结构参考不清时，先改设计/参考，不能只堆“更自然、更固定”。记录旧通过/预算就绪判断的撤回范围，未知仍未核，不用新漂亮图复活退回项。每轮集中一个主要问题，可以联动修改相关句子，不机械限制成只能改一句；其他条件在可行范围保持一致，必要的变化如实记录。若只是剪辑空档、字幕或音量问题，可提出本地后期方案，不一律归因于提示词。

交付问题定位、完整替换文本和简短修改说明，指出需要继续验证的部分。记录新旧版本、主要变量、结果与原有效果是否受损；单次成功不证明稳定改善，未经用户授权不为验证自行提交收费生成。换模型时重新核对参考、语法和参数支持，不直接复用旧模型假设。普通参考槽与明确的起点/终点条件按当次真实字段区分，不能在提示里写“固定参考”便许诺端点锁死；起止相符也不能代验连接结构和中间运动。尚无生成结果时标为文本适配候选。

反馈说“接话像排练过”时，可把争议处连着前后一句回放。先听谁出了声，再看这声音落在谁的嘴、谁正做的事上。留意剪切有没有拿走人物辨认或看向对方的那一瞬。若只是同一画面的放大裁切打断了交流，可以先连回主镜；关键结果看不见时，再把插镜放到动作生效的地方。

外部任务状态不明时先定位已提交任务与实际产物，核当前内容及参考绑定再决定采用；不要为等待重复提交。未取得结果不写成通过。

同一处经几轮改口，项目记录留清用户最后选的原话、它发生在什么动作前后，以及哪条旧指示已被替代。提交给模型的文本只用当前选择。将预览中实际看到的问题、这次改法、下一版是否已回看分开写；只有用户转述时注明来源。

## 来源与适用边界

公开正文查阅日期：2026-11-18。下列是模型使用指导，不是文学质量或本库跨模型视频效果的证明；本页为独立整理，未导入第三方执行流程。

- [Runway Gen-4 Video Prompting Guide](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)：从简到繁迭代、图生视频聚焦运动、正向描述及避免过多冲突动作。其负向提示限制与片长说明只归属文档所指的 Gen-4，不自动用于其他版本或可灵。
- [Google DeepMind Veo Prompt Guide](https://deepmind.google/models/veo/prompt-guide/)：构图、运动、风格、光线、人物与声音的描述维度可按需要选择，不作为每镜填满的表格。
