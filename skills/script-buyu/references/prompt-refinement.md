# 分镜提示词精炼与结果诊断

仅在用户要求面向具体模型整理提交文本，或带生成结果来诊断时读取。完整分镜保存创作意图；提交提示词按输入模式与实际参考整理，不把七列全文和全部审核说明拼接给视频模型。本页只指导文字适配，不自动生成、上传素材、收费重试或修改已确认故事；普通剧本与七列两表交付照常进行。

## 从分镜到提交文本

使用当前源版本和批准范围，识别本段需让观众看懂的行动、关系与信息。保留实际台词、人物归属、关键触发与揭示次序；用户已授权的故事修订另记当前版本，不从旧稿恢复。简短不等于删掉情绪依据或剧情条件。

区分参考图承担身份、布局、首帧或风格中的哪项作用，沿用真实引用名称及绑定。看不到图就标明未核验；资料中的图号不能冒充已上传引用。图生视频可少重复输入图已有的外观；文生视频仍需足够的主体和空间描述。身份参考不自动锁定表情，首帧与布局参考也不自动可被文字推翻。参考冲突先处理冲突，不继续叠词。

具体表演沿用当前完整提示词的细微表演要求：保留情绪如何进入注意、身体、声音和对方接收的有用细节；可与发言并行，也可停下来辨认或承受。删去冗余分解，不删成无情绪的快速问答。不同题材、人物与场面可选不同强度，不固定动作数量、时长或特写。镜头衔接根据已有空间、动作或声音联系安排；不能因画面换了，人物状态和工作就重新开始。声音跨镜延续时，按人物所在的位置和实际声源写清谁能听见、能听清多少。

先写正向、具体且与故事相容的目标；为表现尺度、紧张或气氛补的主体与道具仍须符合当前故事。负面约束及其字段按目标平台、模型和模式的实际支持处理，不将一家模型的禁用建议推广到全部模型。仅保留解决当前错误所需的排除项；Excel 中实际负面文字仍遵守既定加粗标红格式。

## 带结果修订

先取得或定位原完整提示词、对应结果、实际模型与模式、时长及参考绑定；其余参数按诊断需要读取。记录“时间点—实际不符—期望改变”，分清观察和原因假设。无法取得视频或音轨时，只能诊断可见关键帧或文字，不能判定运动、口型和声音表演已自然；ASR只辅助核对播读内容。

先判断问题可能来自剧情表达、参考冲突、指令矛盾、模型执行或剪辑衔接，再选择修改位置。每轮集中一个主要问题，可以联动修改相关句子，不机械限制成只能改一句；其他条件在可行范围保持一致，必要的变化如实记录。若只是剪辑空档、字幕或音量问题，可提出本地后期方案，不一律归因于提示词。

交付问题定位、完整替换文本和简短修改说明，指出需要继续验证的部分。记录新旧版本、主要变量、结果与原有效果是否受损；单次成功不证明稳定改善，未经用户授权不为验证自行提交收费生成。换模型时重新核对参考、语法和参数支持，不直接复用旧模型假设。尚无生成结果时标为文本适配候选。

## 来源与适用边界

公开正文查阅日期：2026-11-18。下列是模型使用指导，不是文学质量或本库跨模型视频效果的证明；本页为独立整理，未导入第三方执行流程。

- [Runway Gen-4 Video Prompting Guide](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)：从简到繁迭代、图生视频聚焦运动、正向描述及避免过多冲突动作。其负向提示限制与片长说明只归属文档所指的 Gen-4，不自动用于其他版本或可灵。
- [Google DeepMind Veo Prompt Guide](https://deepmind.google/models/veo/prompt-guide/)：构图、运动、风格、光线、人物与声音的描述维度可按需要选择，不作为每镜填满的表格。
