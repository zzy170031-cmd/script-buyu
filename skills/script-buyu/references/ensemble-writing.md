# 方法选组、正文统稿与完整性

本文件落实多方法协作的选择和验收。先按 [题材入口](genre-methods.md) 找候选，再按当前问题取舍；方法卡是材料，真实人物不参与、背书或代写。单Agent可以完成全部职责，不默认召集代理。

## 入库资格和本次选用分别判断

入库须能核实相关代表作品与本人写作/导演职责，阅读可定位的创作表述，记录具体贡献和不适用条件。姓名、获奖、爆款或粉丝量不能单独证明本题材可用。官方署名仅证明职责；本人观点另需内容证据。作品分析须明确“我方从指定原作片段归纳”，不得包装成作者自述的秘法。

检索结果提供资格、题材关联、贡献、局限和来源定位。优先选有直接行业/出版方/机构来源支持、能解决当前问题的资料；采访转载或个人平台需保留来源强度和交叉资历依据，不以别处权威署名替某段方法背书。不同署名者共用采访页是多个具名观点，不是多个独立来源。判断的是可追溯的创作经验，不是艺术效果或个人全面资格的认证。

确有多种建议需要比较时，才在现有记录中简记相关问题、取舍依据与允许范围，常规使用不填选组表。真实有用才选，可以不用；不设每场名额、唯一名家导师或全员参与。代表性检查具体路径差异，例如推理的线索公平与人物盲点、战争的战场任务与战后记忆、爱情的关系障碍与双向行动；只换姓名而操作相同的卡择一即可。跨文化素材服从本剧背景，不以文化背景作固定风格标签。

## 一份当前正文与明确统稿责任

### 先确定本剧自身的表达基准

统稿依据来自当前用户意图与已写正文；需要澄清时，再简记相关的叙事视点、人物处境、世界规则或表达方向。创作中的表达可以逐步明确，类型混合和转调不必预先登记理由。新剧按自身内容选择，不继承上部风格。

不同方法只处理被指派的问题。例如用悬疑方法安排揭示、用关系方法深化选择，不因此把同一个人物分别写成侦探腔、诗人腔和段子手。每条建议先核对本剧基准，再选择采纳、改造或弃用；局部名场面若削弱整体人物、因果或情绪，优先改写或舍弃，不因名家来源而保留。

方法合并后按实际修改范围回读相关互动与承接，最终交付时通读完整授权稿。不要把“所有卡都用过”当完成条件。混合题材、反差和转调是否成立，结合人物处境及整体阅读判断；一致性不等于每场相同语气、相同节奏或只有一种情绪。出现声音漂移疑点时，比较处境可对照的完整互动，先区分关系或经历变化带来的合理差异，再定位实际损害，不只把措辞修得相似。

每个实际修改单元（段、场或集，依授权范围）只有一份当前正文和一个统稿职责。其他方法/角色提供可定位的建议，由统稿者比较、取舍、重写后融合，不把独立续写顺次粘贴。每剧可有多条核心矛盾，群像交叉剪辑可同时推进等重双线；“一个统稿职责”不等于“一条主线”或“只能用一位名家”。

需要专业支持时，按 [题材与专业职责](genre-professional-support.md) 指定其允许影响的字段：事实顾问核行动条件，写作方法补当前叙事问题，导演方法澄清文字中的场面；均不自动取得改承诺、决定权、结局或确认内容的权限。建议先交主笔写成候选修改，再由统稿采纳；不要让同段存在几份各称最终稿的正文。

只记录该单元实际需要的表达任务、必保事实/伏笔和视点权限；涉及当前行动条件或后续依赖才记必要状态与变化，也可以不变或待定。对存在冲突的建议，留下最小取舍依据：`建议 → 保留/修改/弃用 → 正文位置或理由 → 涉及的前后依赖`。同功能建议合并，互斥建议依据用户约束、事实规则、人物目标和全篇效果裁决，不能按名气投票或平均混合。

统稿完成后按本次改动比较必保事项、人物知情与决定权，以及受影响的后续行动条件；不逐项解释情绪与偏好。唯一责任人只解决权属，不自动证明合并正确。有实际独立审阅者且宿主允许时由他检查此差分；否则由当前Agent复核相关正文，不冒称独立复核。记录沿用本页及[工作流程](workflow.md)的适用范围，不让用户填表，不另加交付文件。

## 戏份、视点和人物声音

按因果作用而非台词字数分配注意力：谁发起关键选择、承担代价、引出信息或完成关系变化。配角可以高光，群像可以轮换中心；高光应有本剧规定的功能，不能让原定中心人物只剩旁观解释。若角色主动权转移，核对是否是有意的叙事安排；不机械恢复主角优势或平均戏份。

对白受目标、知情、关系、社会背景和表达习惯约束，不让全员变成咨询卡的金句发言者。创伤、成长或策略改变可以改变口吻，但需要事件依据；区分对不同对象的调整、临时策略与长期变化。一次承诺不证明永久成长，未写后续只能记计划中的变化。表达增强按[台词核心](dialogue-craft.md)，不能靠统一口头禅修补整剧断裂。可隐去姓名检查声音是否仍可区分；相近人物允许自然相似，不强造口癖。态度不同不等于事实可以各自随意改写。

## 连贯与完整分层复核

沿用 [场景状态](scene-methods.md) 的时间位置、人物知情、伤势能力、物件、关系情绪和伏笔承诺，不另造第二套设定。不可变事实和可变化状态分开；当前或后续行动依赖的事实变化须能成立，不要求每次情绪、态度或联想有唯一原因。依据可分布于上下文、延迟揭示，非当前必需的疑问可以保留。记录、跨轮恢复及修改传播按 [剧情状态执行页](continuity-control.md) 落实；既查已列依赖，也从正文发现遗漏，不能以台账完备代替读稿。

- **纯措辞修订**：说话者、对象、时间、媒介、事实、知情、意图、称谓、关系、条件、决定权和揭示作用均不变时检查本段和相邻承接。同字换人或换时点不自动算纯措辞。
- **语义或事件修订**：改变知识、态度、决定、时间、能力或伏笔时，追到所有使用该信息的节点及回收场，直到没有未处理的影响。授权外的修改只定位并提出最小修订，不自动重写全季；无法兼容已锁事实时保留未发布草稿并说明冲突。
- **版本里程碑与最终交付**：通读完整授权稿，确认请求范围内所有集/场已写全，必要行动条件成立，用户要求兑现的承诺得到处理。其余关系、动机和谜可以按作品意图悬置或永久留白，不因无法补成因果链就判错。局部精彩不能替代用户要求的完整结尾。

必要铺垫保护与节奏优化同时做：压缩重复解释，保留理解规则、关系、代价所需的信息。喘息场可只承接损失、沉默或安全感；不强迫每场有目标—风险—回报全套。爽感需由已建立的能力、选择、关系和代价支持，续集钩子不能抹掉刚兑现的成果。

## 确认后与交付边界

确认后转译只使用当前卡允许的专用步骤，保护原台词/旁白、事件、结果、因果和揭示顺序。发现上集伤势与本集行动不容时，不用遮挡或快剪掩盖并宣布解决；能忠实表达既定状态才继续，否则指出确切冲突并取得相应正文修订授权。

DOCX含人物提示词而不嵌图，少量代表人物示例在文外；文本与视觉方向确认后，批量人物图进入两表Excel。选组、取舍和状态记录都是内部材料，不添第三张表或额外默认交付。

需要检查合并方法时，按需读取本Skill内的 [一致性案例](ensemble-writing-example.md)。这是机制演练，不是文学质量或观众效果认证。

方法是否改善文字，用 [文本试读](text-review.md) 保留原稿、具体取舍与修订后果；允许不用方法、原稿更好或效果未明。已有连续性记录继续沿用，不另造一套表，不要求制作测试。
