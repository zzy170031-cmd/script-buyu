# 台词修订工具：人物声音、DL方法与试读

先读[台词核心](dialogue-craft.md)。仅在实际问题出现时查本页；以下是本项目编辑操作，来源启发不等于作者原公式。不要求逐句填表或每场使用方法。

## 2. 需要辨认人物声音时

从已有设定和正文中查找对当前问题有用的线索，以下角度按需取用，不给每名角色另填声音档案：

| 维度 | 需要知道什么 | 不要写成什么 |
|---|---|---|
| 注意力 | 进入局面先注意损失、面子、人、秩序还是机会 | 只列年龄、职业、MBTI |
| 语言资源 | 亲历经验、会用的比喻、不会用的术语 | 所有军人同一种腔、年轻人必讲网梗 |
| 习惯手段 | 先问价、先认错、先解释、先开玩笑等；可变 | 每句都出现一个口癖 |
| 难说出口（可无） | 什么事实／请求让他有实际代价，或人物尚未意识到什么 | 给每人强装秘密与创伤 |
| 对人变化 | 对上级、盟友、陌生人、亲近者如何调整 | 所有关系各生成一套互不相干的人格 |
| 压力变化 | 恐惧时多说还是少说、如何掩护自己；依据何在 | 激动就统一加感叹号 |
| 实际变化 | 某次变化是否影响后续事实、选择或理解 | 把临时反应登记成永久性格；用成长掩盖突然全知 |

性格只是理解人物的基础，见[人物写作](story-craft.md)。声音可以在草稿中逐渐明确，首次推测不锁定后续反应。统一基调可以存在，人物差异也不必在每一句话里证明。

## 5. 有界方法菜单

按问题选一两种；无缺陷不硬套。下列为本项目编辑方法，不冒称名家原公式。

| 编号／方法 | 适合修什么 | 操作 | 失败边界 |
|---|---|---|---|
| DL01 对象与请求 | 对空气讲道理 | 把抽象立场变成对眼前人的具体要求 | 不擅自更换人物目标 |
| DL02 听见后变招 | 两个人轮流独白 | 让下一轮针对对方新抛出的障碍调整 | 不要求每轮反转立场 |
| DL03 事实争用 | 说明书式科普 | 同一事实用于争取、拒绝、分责或校验 | 不改领域规则制造戏剧 |
| DL04 知情账本 | 人物替观众问常识／全知 | 分开角色已知、误知、观众未知及信息来源 | 不用神秘语气补缺证 |
| DL05 代价与遮掩 | 直抒全部心理或故作含蓄 | 先看代价、礼貌、习惯或不自知是否解释了保留，再选可理解的说法 | 真诚告白与危机指令允许直说 |
| DL06 托物与行动 | 表白解释太满 | 用已存在物件、承诺或小行动承接关系 | 不凭空加入纪念物、欠债或往事 |
| DL07 自我修正 | 中文过于整齐书面 | 允许改变称谓、收回一半、先顺口再补救 | 不批量加“呃、那个、你懂吧” |
| DL08 面子与位阶 | 全员一个语气 | 看谁有拒绝权，选择让步、装不懂、给台阶 | 不把强者等同少话、弱者等同啰嗦 |
| DL09 笑点归人 | 全员段子手 | 让幽默出自其认真目标和不同关注点 | 不为包袱让角色变笨或无视死亡 |
| DL10 长短呼吸 | 句句短平狠／读不顺 | 压缩重复句，保留关系铺垫，短句落在必要处 | 不固定字数或“每句必新增信息” |
| DL11 回扣兑现 | 口号式爽句 | 已有说法因行动、代价或关系变化得到新含义 | 不预埋满篇口号等着回收 |
| DL12 倾听与沉默 | 配角只剩接话或哑站 | 检查不说话的人是否作出有意义的反应 | 不靠不停挑眉攥拳充字数；沉默不自动等于同意或原谅 |

## 7. 写后分四遍看，按缺陷选择，不固定返工次数

**人物遍**：在必要上下文中交换关键台词的说话人，是否仍完全成立？相似职业／短命令自然相近，不按姓名竞猜正确率硬判人物失败。核对在意之物、选择和承担，而不只看词汇。

**往来遍**：完整互动中，各人是否听进了对方的话，或在可信地忙别的事、误解、回避？普通问答与无策略闲聊不必变招。承接影响理解或后续选择时再定位具体问题，不逐句索取因果解释，也不凭“现实会这样”自动判定好读。

**理解与口语遍**：只读实际说出口的文本，检查指代、术语、呼吸和信息负担；文字聊天同时检查消息到达与操作的先后。随后恢复观众当时可得到的动作、字幕与获准旁白，回述其能理解的行动和关系，确认潜台词有线索；内部工作解释不能充当观众已知。没有真人朗读或音频就写“桌面文本检查”，不声称配音自然或精确时长。

**整剧遍**：沿实际改动检查受影响的事实、知情、承诺与后续行动，最后由唯一统稿者读完整授权范围。比较人物、节奏、幽默和余味是否受益；不逐场登记性格或情绪轨迹，也不让局部好句损坏整篇。

## 10. 专业资料如何使用

- John August / Craig Mazin 本人公开 Scriptnotes609：提取换说话人、人物与作者声音、权力变化的检查方法。https://johnaugust.com/2023/scriptnotes-episode-609-dialogue-and-character-voice-transcript
- Dee Rees 的 BAFTA 公开讲稿：提取人物为何回避直说、开口的后果、借既有具体事物谈关系；不把其举例的“三次退让”强制成公式。https://www.bafta.org/media-centre/press-releases/bafta-screenwriters-lecture-series-dee-rees/
- Andrew Bovell 的 BAFTA 公开讲稿：提取说不出口、沉默和动作的表达作用；不把拍摄协作扩张成当前项目的试拍任务。https://www.bafta.org/media-centre/press-releases/bafta-bfi-screenwriters-lecture-series-andrew-bovell/
- 复用[学院资料](academic-methods.md)中的AFI A01：反馈定位到具体文本。课程简介不是已完成课堂训练，不声称演员实际围读。

上述仅为方法来源。中文口语、AI漫剧效果和本项目适用性由实际片段与后续盲比检验，不由名气自动担保。
