# 代表作品与电影学院资料的使用

经典作品、创作者公开讲解、电影学院教学资料各自提供不同证据。先识别本场问题，再选择一种具体机制；进入 [统稿流程](ensemble-writing.md)，不以名望替代适用性，也不模拟真人或学院参与创作。

## 从代表作品提炼

记录作品名、实际阅读/观看版本、场次/章节/页码或时间段、可观察的文本或视听事实、我方解释、迁移步骤及失效边界。未读原作、只读采访时，写“本人对作品的公开讲解”，不可写“已完成原片拉片”。现有方法库区分 `creator_statement_adaptation` 与 `primary_work_analysis`，后一类目前3条，分别依据奥维德《变形记》伊俄段、埃斯库罗斯《波斯人》《七将攻忒拜》的指定可见文本段落。

分析先问：这一段改变了谁的行动、知情、关系或观众期待？具体依靠哪项铺垫、限制、重复、空间或声音安排？换成另一个题材后哪些前提失效？将操作移植到本剧，保留本剧人物的决定、声音和后果。不复制经典桥段与台词，不把相似表面当成有效机制；作者没有亲自解释的推论明确归属本库。

作品署名只能支持职责，奖项与经典地位只能辅助选材；均不能证明某个具体方法或AI漫剧效果。缺少可定位原作或本人讲解，保留为待研究，不用熟悉片名填补证据。

### A01 反馈落到具体文本

1. 选出本轮授权范围内的一段完整场面，固定版本，分角色通读台词和必要动作；记录实际遇到的理解或表达问题，必要时回看说话对象、关系和当时在做的事。
2. 每条反馈对应具体句、动作或缺失的铺垫；区分文本缺陷与朗读表现。由唯一统稿者决定采纳、改造或弃用。
3. 再通读修订片段，检查原问题与新增问题。没有实际读者/演员时，记录“作者桌面检查”，不能编造围读反馈。

检查：修改是否缓解已指出的问题，原有趣味、关系和前后承接是否受损；场面可以顺畅交谈或安静相处。边界：纯动作、故意错认和隐瞒场景按其意图判断；文本通读不能证明表演自然或画面成立。无需生成配音文件，不新增默认交付。

### A02 图像与声音分工

1. 在草稿中逐段写清可见动作及进入/离开状态；需要分镜时使用内部文字草案或已获批的Sheet1。
2. 分开检查画面能传达什么、声音又新增什么；定位重复解释、缺动作却宣称结果、必要信息完全丢失之处。
3. 草稿可在授权内修改动作/声音；确认后仅调整已允许的画面表达，不改台词、旁白、事件结果、因果或信息揭示顺序。发现故事问题先报告。

检查：图像与声音合起来足以承载本场叙事意图。边界：音乐叙事、抽象或有意歧义不强制静音即可看懂；这是学习目标启发的文本适配，不是完成USC课程或动画实作检验。无需生成动态镜头。

### A03 系列承诺与首集一致

1. 用简短内部记录写明持续冲突、人物关系、语气，以及本剧希望每集提供的观看体验。
2. 对照首集实际行动，检查是否展示该承诺；抽看后续情节是否产生新困境、积累关系变化，而非复述首集。
3. 定位差异后，在授权范围内修改系列设计或正文，沿依赖回查。短篇、单元剧和非情节叙事按自身组织方式判断，不强迫持续主线。

检查：首集的吸引点在后文有发展，变调有铺垫，初稿仍需修订。边界：公开课程面向电视；没有据此证明短视频留存、付费点或固定篇幅有效。系列记录仅为内部工作资料。

### A04 表达转换后的意图回查

1. 找出一场容易在分镜转换中丢失信息的场景，标记观众必须理解的角色决定、空间关系与后果。
2. 将这些内容逐项对应到文字分镜的动作、主画面、运镜、台词，查找遗漏和相互冲突；同时查人物ID、道具与知情状态。
3. 统稿者决定表达调整。已确认剧本存在问题时只列受影响范围，获修改授权后再改正文与相应确认；不要用镜头遮挡问题来伪装事实正确。

检查：正文意图在Sheet1有可指出的表达位置，且不更换决定、结果或揭示顺序。边界：仅受NFTS制作检验理念启发，当前执行的是更弱的桌面检查，不能声称成片、可生成性或剪辑效果已验证。无需试制视频或增加第三份交付。

## 无言动作训练的已读范围

需要练习动作完成点、衔接或画面/声音记录时，可定位已有N02：[MIT Playwriting I Week4](https://ocw.mit.edu/courses/21m-604-playwriting-i-spring-2005/90ea12b69664c9e3b4bf3988a52e2c2a_week4.pdf)。既有研究记录实际读取完整一页L0–15；这是无言动作与声音的课堂训练，不是成品禁对白、禁心理的规则。可借它试查某段动作做成什么、下一段怎样接，也可直接保留已成立的对白/叙述，不要求每稿做无言练习。尚未完成课堂作业或获教师反馈，课程主页Spring2005与部分讲义Fall2005页头差异保留；本轮只核旧自写范围，未重读官方PDF。它提供有限训练参照，不宣称成稿改善或新增学院认证。

## 接入时机

动画身体表演、实验动画及声音取舍的补充依据见[方法参照与评审角色R04–R06](representative-review.md)：John Canemaker本人方法与NYU历史课程、TAW/VIA纲要、CalArts课程简介，以及Walter Murch在NFTS的具体大师课分别标明证据范围；R03将已有中戏《雷雨》工作坊接到中文人物审读。新增文字适配为增益未证的可选候选，仅按问题使用，不把培养目标、经典作品或校友经历互相替代为课程证据。

创作前只选与缺陷相关的卡；写完由统稿者核对影响。A01/A03用于草稿或获授权修订，A02/A04用于相应阶段的文本/表达检查；进入确认后必须服从 [Excel约束](storyboard-excel.md)。保留用户指定故事样式，不把课程训练方式变成新模板。无法执行实际练习时说明采用了何种桌面检查，不能把阅读简介写成专业训练已完成。
