# 情绪表达与转折

先读[台词核心](dialogue-craft.md)，只在情绪表达或转折有具体问题时查本页。以下 16 组是选词和互动的观察入口，不是完整心理分类、诊断标准或“人只会有这些感情”。每类允许多种强度、混合与转换，也可以不用标签。

## 先区分四件事

人物感受到什么；人物选择或不自觉地怎样表达；对方可能理解成什么；预期观众产生什么感受。四者不必相同，实际观众理解待检查；听者理解没有回应依据时保留未知。人物因为害怕而凶，听者可能觉得被嫌弃，观众可能先感到好笑、随后心疼。必须在正文给出足够线索，内部标签不能替读者理解；仅在需要诊断时简记，可省略，不塞入交付JSON的必填字段。

不预设“愤怒=大喊、悲伤=流泪、爱=嘴硬”。表达还受对象、场所、习惯、当下任务与身体状态影响。稳重者也能失控；原因和余波需要写出来。

| ID／感情色彩 | 当事人可能在乎什么 | 可选表达及接话方向 | 容易写坏的地方 |
|---|---|---|---|
| EM01 喜悦与兴奋 | 分享、被看见、终于获得 | 抢着说细节、找特定人分享、反复确认好消息，也可只是难得主动开口 | 所有人一起高喊口号；把兴奋写成永久性格改变 |
| EM02 安心与信任 | 不必防备、愿意交出一部分控制 | 允许说普通话、提出小要求、承认不会或一起安静待着 | 无冲突便删戏；把一句放心当作所有问题解决 |
| EM03 好奇与期待 | 想知道、想尝试、想靠近 | 具体追问、试着猜、接受纠正、等待对方继续 | 角色替观众问已知常识；每问必制造悬疑 |
| EM04 爱慕与依恋 | 希望被回应、希望连接持续 | 记住小事、直接邀约、试探意愿、分享自己而非只观察对方 | 单方逼近被当作浪漫；所有人都嘴硬 |
| EM05 感激与敬重 | 对方做的事被承认 | 说清受益之处、接受帮助、回馈但不急着结清 | 夸奖像颁奖词；感谢变成人情买卖 |
| EM06 骄傲与成就 | 付出被证实、能力被认可 | 指出具体成果、选择向谁展示、克制或放开庆祝 | 不断踩别人；结果尚未成立先放胜利宣言 |
| EM07 愤怒与不满 | 边界受损、不公或阻碍 | 可以讲清要求、控诉细节、冷处理、争辩或失控；听者不必立即认错 | 统一吼叫；合理愤怒被一律改成潜台词 |
| EM08 恐惧与焦虑 | 威胁未知、担心失去控制 | 反复确认、求具体步骤、强装镇定、说快或说不出；都要有人物依据 | 删掉所有重复；让害怕的人自动变愚蠢 |
| EM09 悲伤与失落 | 已发生或即将失去什么 | 可以直说难过、问实际事务、保留习惯、拒绝安慰、长久沉默 | 统一流泪与诗句；把沉默当唯一高级表达 |
| EM10 愧疚与懊悔 | 自己做错什么、能承担什么 | 认具体责任、纠正借口、询问可做的事；对方可拒绝修复 | 自责抢走被伤害者的戏份；说抱歉就免责 |
| EM11 羞耻与难堪 | 自我形象暴露、怕被轻视 | 换称呼、解释过多、转话题、反击、承认或请求保密 | 窘迫等于贫穷/弱势；凭空推断创伤 |
| EM12 嫉妒与比较失衡 | 别人获得自己也想要的东西 | 过问分配、过度恭喜、减少回应、坦言失落或认真竞争 | 嫉妒者必恶毒；所有竞争都写成嫉妒 |
| EM13 怀疑与戒备 | 信息、承诺、关系是否可靠 | 追问来源、限定承诺、保留判断、要求可验证的小行动 | 人人侦探腔；无依据否认一切拖戏 |
| EM14 厌恶与排斥 | 不愿靠近某行为、关系或处境 | 明确拒绝、减少接触、转开话题、质疑做法 | 用贬低群体代替具体对象；只堆恶毒形容词 |
| EM15 惊讶与困惑 | 预期被打破、暂时无法解释 | 复述关键词、核实、短暂停住、改问新的问题 | 每次都“什么？！”；立刻全知解释 |
| EM16 无奈、苦涩与释然 | 愿望与现实的落差正在被处理 | 接受某一限制、保留另一诉求、苦笑、直说放下或继续生活小事 | 自动写成鸡汤大彻大悟；接受现实等于赞同伤害 |

## 同一种情绪，表达可以相反

同样担心队友，甲先问“你在哪”，乙先骂“谁让你一个人去的”，丙先处理“地址发我”。选择哪个取决于已写的人物经验和关系，不按职业、性别、年龄刻板分配。也不能为了可区分而让三人在同一紧急频道各说一遍；真正入稿时只保留有作用的互动。

同一个人也会变：面对陌生人可能先客气，面对亲人可能急躁；被追问后可能从辩解转为承认。这是对象或事件驱动的调整，不需要为每种情绪重新创建人格。称谓、句长和音量暂变不自动等于人格漂移或关系升级；但涉及承诺、知情、决定权和边界的变化仍须查语义与后续影响，失控不能豁免。

## 混合情绪写在选择上

| 混合状态 | 可落到正文的矛盾 | 需要避免 |
|---|---|---|
| 爱与怨 | 愿意帮忙，但不恢复旧称呼或不接受道歉 | 一次照料就等于彻底原谅 |
| 怕与担当 | 承认害怕，同时仍做已经决定的事 | 担当者突然不会害怕 |
| 喜与愧 | 分享成功时意识到别人付出的损失，调整表达 | 用一段自责抢走他人的损失 |
| 骄傲与自卑 | 想展示成果又先自我贬低，听到回应后再变化 | 全程套“我不配” |
| 悲伤与幽默 | 用共同生活细节短暂找到亲近，笑后悲伤仍在 | 笑点抹掉刚发生的死亡或痛苦 |
| 愤怒与依恋 | 设边界但仍希望关系继续，话里包含明确条件 | 把控制与伤害自动解释为爱 |
| 释然与遗憾 | 接受某个结局，同时保留失去的分量 | 最后一场人人豁然开朗 |

不强制“主情绪+副情绪”配额。没有冲突也可以是单纯快乐、专心工作或平静交流。

## 转折需要可追溯的依据

有争议的转折可按此诊断：旧判断 → 新听到/看到的事 → 对此事的理解 → 表达或行动改变 → 尚未消失的余波。这不是必经结构；依据也可来自前文蓄积、身体状态或已经成立的时间过程，不要求当场新增刺激事件。不能为显得情绪复杂而擅加秘密、债务、创伤、回忆或牺牲。

例如道歉场：防备 → 听到对方承认具体行为 → 试探其是否愿承担代价 → 暂时允许继续谈。拥抱可表达复杂反应，不自动等于原谅、恢复信任或责任清零；是否靠近及靠近到哪一步由正文支持，不强制分场。另一场可以从期待到失望，关键在对方哪句回答或哪个行动使期待落空。

镜头、表情、动作提示只描述可呈现事实。若写“笑了”，不能未经文本支撑断言观众必然理解为“掩盖嫉妒”。把必要线索放入互动，而非无限增加括号心理解释。

沉默不能自动成为同意、原谅、已知信息或作出承诺。后续行动若依赖这些条件，须有足够言语、行动或已建立约定的依据；没有就保持未知。人物可以误判沉默，但他的判断不能替代事实记录。必要的命令、许可、认责、时间和边界允许直说。

## 快节奏的调整位置

优先压缩重复立场、无效铺垫和已经被动作说明的复述。保留让观众知道为何生气、为何接受、为何拒绝的最小线索。短句可以是爆点，长句可以暴露控制欲、努力讲理或难得坦白；对比由本场决定。不设固定秒数反转、字数上限或情绪峰值次数。

实用检查：观众能否用自己的话说明“他现在为什么这么说，对方因此怎样回应”；不能只复述“这里是愤怒风格”。
