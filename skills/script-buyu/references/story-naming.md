# 书名、剧名与章集名

需要拟名、改名，或标题读起来像工作说明时使用。先分清作品正式名称、章／集名、内部事件标签与发布标题；它们可以相同，也可各有用途，不自动把大纲里的概括搬成正式名称。已有名称按本轮授权处理，格式整理不顺带改名。

作品名考虑整部作品给人的期待与辨识；章集名结合该段经历、声音和阅读位置选择。名字可以来自人物、称呼、事件、对白、地点或意象，也可以直接陈述；这些是可能的来源，不是待填的类别或轮换公式。取舍依据是本作的语言与内容，不靠堆题材词、缩成四字或增加隐喻来证明文学性。普通词语、长标题、数字编号和有意重复均可能合适。

先定名字、途中发现或后期调整都可行。只读到首章或梗概时，整部作品的候选名仍需结合全稿复核；不要为凑合一个漂亮名字补写情节。标题可提示读者本作允许先知道的事，也可保留未知，不能无意泄露身份或结果，更不要求每章都设置悬念。

回看正文后连读目录：名称是否有本作依据，是否让读者期待了正文没有的故事，是否反复用同一种概括方式而失去各章特点。统一回目或系列重复有其表达作用时保留。单纯准确还可继续斟酌声音与吸引力，但审美建议不充当硬性错误；原名合适则不改，不为证明用了方法而强出候选。

正式书名／剧名与封面、单条视频的发布文字分别按用途处理。发布适配见 [对应参考](douyin-publication.md)，不让某平台标题习惯统管整本目录。生成和排版继续使用既有标题字段，不增加命名评分或寓意说明到作品正文。

## 参照与验证边界

东西在[《回响》访谈](https://www.chinawriter.com.cn/n1/2023/1114/c405057-40118049.html)中谈到，书名在写作中途由两条线索的关系而来；王十月在[《不舍昼夜》访谈](https://www.chinawriter.com.cn/n1/2025/0208/c405057-40414968.html)中说第五稿才定名。2026-11-15核读相关问答；这两个个案支持允许随创作调整，不证明后起名更好，也不提供通用命名公式。

本页为有界的编辑指导。维护时可用相同正文比较原名与候选，保留原名胜出、相当与无法判断的结果；需保留未参与规则设计的材料和原本合格的标题。有限模型试读不等于真人偏好、传播成绩或跨题材普遍收益。
