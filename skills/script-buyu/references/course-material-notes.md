# 课程材料阅读与实写取舍

本页供材料转写、人物构思和修订时选读，接[课程入口](writing-courses.md)与[文本试读](text-review.md)。资料范围为2026-09-30研究的53份用户提供中文文件。按可提取文字通读，另核部分原页与嵌入图；没有完成全部课件的视觉复核、课堂作业、音视频或教师点评。多数课件的机构与传播链未核，标题不构成学院背书。这里保留阅读定位和应用判断，不随 Skill 分发原课件或整段作品摘录。

## 课程中的讲解过程

|资料与定位|实际教学内容|可以怎样使用|
|---|---|---|
|《编导电影剧本写作、剧本分析课件(1).pptx》第4—5张|把同一段小说材料转成夫妻对白，人物立场有所区分；对白也重复了双方熟知的旧事|比较信息怎样进入当前交谈。改成“人物名＋冒号”不保证自然，成对例文也可能有各自的损失。|
|同课件第21、29、31—36张；第38—40张|以连续案例联系经历、需求、观点与行动；另用梗概展示前史逐渐被人物发现|人物性格和经历帮助理解关注与选择；作者知道的前因，可以在故事需要时才显露。人物传记的篇幅不决定正文该解释多少。|
|同课件第26、36张作业及第72张说明|主题大纲、人物传记练习；另归纳26种情节组织方式|按当前问题选练习。26种是情节归纳，不是26种题材，更不规定科幻、家庭或历史各用一种固定结构。|
|《剧本写作.ppt》文本记录36—48、92|关系、事件、时空压力与不同层级情境；以《小鞋子》联系需要和行动|从正在发生的事理解接话、注意力与行动限制。记录号不是已核实的幻灯片页码；小品练习的场数和比例只适用于该练习。|
|《电影剧作理论与技巧-电影剧本的写作过程及规范格式.pdf》第7、19页|区分作者使用的分场大纲与正文；四项作业涉及不同体量梗概、分场、片名与宣传语|同一故事的信息会因用途而取舍。创作备注帮助作者把握事情，不需要逐项变成人物发言；该章流程是可研究的方法。|
|《电影文学剧本的写作基础.docx》“电影剧本的文字形式”“小说和电影剧本的不同”“性格”|讨论文学可读性、具象表达和依附具体动作的必要解释；认为人物构思不必逐项拆解心理因素|文采、动作和适当说明可以共存。连读解释的用途与冗余，不能抽成“一律删除心理”或“一律补足动机”。其对白描可读性、技术说明的绝对判断仍是作者意见。|
|《影视文学剧本写作.pptx》文本记录66—72、85—86、92—93；《影视文学剧本的创作.ppt》记录14起的《辛德勒名单》片段|比较剧本形态与结构，讨论视听表达、台词及开放收场，并以片段展示组织方法|用完整片段检查媒介与表达的得失；记录号不冒充页码，特定收场偏好及片段禁例不升级为全题材要求。|

编导系列四个文件有共同正文，以课件(1)定位为75张幻灯片，另有3个空备注记录；知识讲解版第3张是图片，不能凭文字层空白判漏页。《电影剧本写作与赏析》的PPT/PDF近似版本也应合并理解来源关系。重复传播不增加独立证据。

其他材料仍有用途：提纲型培训课件可定位问题，带例文和练习的章节可研究具体过程，AI情节汇编可供比较。它们的证据强度不同；不能因标题带“AI”全部弃用，也不能把列出的案例点评当作已经接受点评。

## 四场试写带来的实际取舍

在冻结版本 `729560b` 上做了四场、八份首稿：两场修订，两场原创。两位写作者读取相同核心材料，其中一位额外读了课程转化候选及研究、题材参考；两位独立审阅者分别检查匿名文本的阅读感和连续性。单次同类模型试写、组合材料差异及输入构思都限制归因。以下是局部阅读证据，尚非跨题材稳定改善的证明。

|场景|可保留的具体发现|仍不能据此得出的结论|
|---|---|---|
|荒野遇险后的接报|停运被拒后追问“那巡检呢？”，使另一项请求被回避的过程清楚；不必让小七分析官员的心理|追问、疼痛和动作插入越多越自然。原有结尾仍可更简洁。|
|和睦家庭夜宵|补一只空碗即可理顺分食；“我说先吃两个”等原话值得保留|为了完整说明母亲等饭，就应替换原有家常话或增添家庭矛盾。|
|正式职场谈判|“不会改着改着，四条又往后拖吧？”有真实交付顾虑；另一稿解释人员排期，说明为何同日与延期费用不同，也有用|长句必然刻板，或两版中一版可以整体判优。承诺当天发方案与正文展示已发送也需分清。|
|刘禅与诸葛亮议事|小范围的问人名、开始看第一项，使承担工作较具体；一位读者更喜欢给刘禅继续想的余地|君臣场已经足够动人。两稿仍接近讲解安排，输入预设的提问、回应与承担路径也可能有影响，尚未单独验证。|

这轮没有把整份候选转成默认写作指令。可以借具体发现修对应场面，常规写作仍沿用[台词核心](dialogue-craft.md)：人物正面对什么、对方实际接住什么，以及这段文字留下什么感受。课程方法和人物履历帮助理解，正文不必承担证明所有准备工作都已完成的任务。正式说明、普通快乐、长谈和沉默各按处境成立。

后续要判断某条方法是否可靠，应留下可比的首稿与阅读分歧，按受影响的问题复试。已经自然的段落可以保留；课程声望、结构通过和资料数量不能代替用户的阅读判断。项目档案标识为 `Skill实写验证_20260930`，含 `run-manifest.json`、`四场完整对照.md` 与 `reviews/文学盲读.md`、`reviews/连续性盲读.md`；前置课程档案标识为 `写作公开资料_J10_20260930`。本页不要求每次创作另做八稿或新建表格。
