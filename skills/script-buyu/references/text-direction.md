# 剧本文本中的场面组织

本页是本库的编辑操作归纳，不是新名家的授课或制作流程。用于动作、空间、声音事件、信息呈现难以从文字读清时；一般场景无需逐项填表。先服从本剧视角、已定事实和[统稿边界](ensemble-writing.md)，再按需要选D/G/X方法。导演方法服务读者理解和场面感，不要求试拍、配音、生成视频或成片实验。

## 空间、行动与选择

先从正文找出谁在哪里、想做什么、受什么阻碍，再沿关键动作阅读到结果。检查读者能否指出动作为什么可以发生、谁因此改变下一步。只有相关时才记录入口、遮挡、距离、耗时、伤势、能力与物件；不能靠快节奏省掉关键因果。

群戏逐次查明谁发现、谁建议、谁决定、谁执行、谁承担后果。可以由不同角色完成，也允许有意转移中心；不可因某位方法来源擅长群像，就把用户已锁定的决定分给配角。少写动作名词堆叠，多写改变处境的动作及回应。纯文本复述若还原不了路线，先补清指代或必要空间关系，不能擅自增加捷径。

## 声音事件与知情

有关键呼叫、广播、电话、歌唱、回声、遮蔽或静默时，检查 `声源/媒介 → 谁可听见 → 听见多少或误听什么 → 据此采取什么行动`。读者读到了旁白，不等于在场人物听到了；人物猜测不等于事实。声画错位在本页指文字中动作与声音的呈现关系，不要求真实音轨。

保留原文事实的确定程度：已知声音来自哪个空间，但不知道具体发声物，是两层信息。为保留后者的悬念，不得把前者也改模糊；反过来也不能由已知方位补出未知声源。确认后改述既不能新增事实，也不能丢掉影响读者理解的已定条件。

遮蔽一个字、延迟一条消息或改变声源，都可能改变承诺、知情或因果，不是自动获准的气氛润色。静默可能是环境、断线、犹豫或拒绝，不能默认接受。关键声音没有写明听者时，依据现有空间判断可确定的范围，不能补造所有人在场；关键不确定项进入未决记录。

例：正文已定“女儿在走廊听见父亲叫她，母亲在隔音室”。新增雷声把呼叫完全盖住，会破坏女儿回应的原因；写母亲听见后转身则新增知识。若只让女儿停步、按原意回应，可澄清既定动作。若故事明确需要未被听见的呼喊，则它属于另一种已授权事件，不能用本例强迫所有呼喊传达成功。

## 信息和文本节奏

分别追踪事实发生、正文呈现、人物知情、读者可推断。悬疑可以误导、不可靠叙述可以成立，但需符合本剧既定视角；后面的揭示要能回指已有依据或明确的新证据，不能倒改先前的客观事实。

例：S1只出现红手套，S3才首次确认医生身份。S1补出袖口姓名会提前揭示，即使一句对白没改；若原约定是读者先知、人物后知，则同样的文字可能合理。先看本剧信息约定，不一律禁特写、误导或倒叙。

文字节奏按阅读效果调整停顿、句长、段落和动作密度，不固定每几秒反转。紧张段保留行动前提，胜利保留获得依据与代价；喘息、幽默、日常和余波不必再造冲突。文本可朗读检查拗口与往来，但不要求真人表演或精确片长。

## 确认后的使用

带 `confirmed_translation` 的卡只使用 `confirmed_steps`，不得混入草稿steps。D01–D08供手动选用，题材检索的G卡仍遵循原检索范围；这些D卡没有因此变成新增题材人数。

确认后只忠实表达既有事件、对白、旁白、结果和揭示顺序。即使写在动作描述、主画面或运镜栏，新反应、目击者、决定和声源仍可能改变故事。缺逻辑就定位问题，按现有授权处理正文，不用镜头词遮掩。没有确认后专用步骤的卡不得用于构造已确认稿的新内容。
