# 微表情与细微表演提示词库

供小说／剧本正文生成、修订及已有剧本的分镜转译按需使用。当前稿 v0.2，2026-11-15。本库是重新编写的表演选项，允许按场面跳过、缩写、替换或组合；尚未验证实际图像或视频生成效果。

这里的“微表情”按创作需求包含细微面部表情与短暂反应，不把整段表演都定义为心理学意义上的微表情，也不把某种表情当作判断真实心理或说谎的证据。

## 何时读取

当正文或分镜中的关系、情绪、接收反应需要更具体的表达时，选读对应类别。正文先看下节的叙述取舍，分镜再看景别与七列写法。已有描述足够时沿用；空镜、背影、遮脸、远景或有意不显露反应的镜头可以跳过。库中没有合适写法时，直接根据本场设计；无需为未使用条目解释理由。不将本库整体粘贴到每个生成提示词中。

检索入口：
- 接收、疑问、意外、领会：M01—M04。
- 委屈、压怒、强颜欢笑、欲言又止：M05—M08。
- 接纳、心动、重逢、关切：M09—M12。
- 疏离、试探、拒绝、轻蔑：M13—M16。
- 失望、骤失、悔意、苦涩：M17—M20。
- 警觉、恐惧、难堪、脱险：M21—M24。
- 决意、不甘让步、和解、放下：M25—M28。
- 忍笑、欣赏、忍痛、疲惫：M29—M32。

## 正文中的使用

小说与剧本先服从[场面组织](text-direction.md)中的视角、注意、身体与话语关系。本库提供可改写的细节，不要求把正文变成五官运动记录。正文可保留直接心理叙述、概述、节奏与意象；第一人称能感觉到脸热、嘴唇发紧，并不自然拥有外部镜头看到的完整面部形状，具体可知范围依本篇叙述约定判断。

原创与授权扩写可以构思新事件、动机和关系，再选择适合它们的表现；这种创作决定来自本轮故事任务，不来自表情分类。修订已有稿件或忠实转译时，按授权范围保留已定事实、原话要求、知情与含混，不用细节偷偷替人物认出、答应或原谅。

在完整交流里选择有用的反应：它可能使话尾变轻、让说话者改口，也可能与原话并行或稍后才显出来。无需总在对白前铺动作，接收者也可以照常做事。表情、动作、对白与心理文字可互补，不必轮流复述同一情绪；顺着前后行动看读者是否更容易理解，原本成立的地方可以不加。

例如，忠实修订中原句“我知道了”仍容许理解与敷衍两种读法，就不靠“会意地点头”替它定意。若原创本来要写敷衍，可在授权情境中设计相应接话或行动，不必先把敷衍拆成眉、眼、嘴三项。这是选择说明，不是各题材套用的对白。

## 从本场到可见表演

以观众对场面的理解和人物可信度来选择细节，不以满足条目数量来验收。与当前剧本相容的细小表演可以由导演表达补足，不要求源稿逐字写过；保留原稿的含混、留白和已有非写实约定。

在已定场面的转译中，先确定角色正在接收什么、注意哪里、关系与状态如何。保留承载故事含义及用户锁定的表演；未写明的细节可作相容选择，不能借此新增秘密、爱意、背叛、原谅、伤势或人物知情。具体呈现可以调整，原有含混也可以继续保留。

可组合的描述因素是：注意落点、眉眼变化、嘴角／下颌变化、必要的呼吸或身体反馈、变化的先后与收束。它们是选择范围，不是每镜填满的字段。通常选少量最能让观众读懂的变化即可；细节较多时按实际表演关系组织，不因数量自动切镜。

让动作落到可见部位：“目光由门把移到来人的脸上”比“眼神破碎”更可执行；“唇角抬起后停住”比“内心复杂”更可观察。情绪名称仍可作简短方向提示，与可见描述相互补充，不全面禁止情绪词。不要靠“瞳孔颤抖”“眼里的光熄灭”等隐喻承担全部动作信息；本剧已有非写实约定时按其规则表达。

变化可以是逐渐出现、短暂闪现、停留、回落或维持；不强迫每镜经历同一套阶段。微小的面部变化可以与身体动作、说话、运镜并行。确需说明时间关系时使用本场触发点或已有时码，不新增固定秒数、帧率或通用时长上限。

## 强度、景别与画风

- 强度取决于人物、场面和当前表达。克制时可只改变目光或唇角；明显时可让眉眼与口部共同变化；强烈时也不必让所有部位同时动作。库里的句子不等于必须全部执行。
- 特写可使用眼睑、唇角、下颌等局部；中景需结合转头、姿态等观众能辨认的动作；远景优先利用整体动作与停顿。不要仅为展示表情库而改成特写。
- 看不清、被遮挡或处于焦外的细节，不当成画面已经呈现的信息。有需要时利用原场可见的头部方向、肩背和声音承接，不为补齐五官而改造构图。
- 写实、二维动漫、三渲二及其他媒介各用本剧已确认的表演约定。动漫可通过眼形、眉线、嘴形及有意停格表达；汗滴、符号眼、夸张变形等仅在本剧允许时选用。细微表演不等于取消已有夸张，也不要求动画增加皮肤毛孔、肌肉拉丝或泪液写实。
- 同一情绪可以有不同表演。冷静人物不必次次咬牙，内向人物不必次次低头；人物的表达习惯是参考范围，不是每镜重复动作。停住、没有明显变化或不回应也可以成立。

遮眼、焦外、画外交流等需要短例时，按需读[画面与表演选用](visual-scene-examples.md)。可见表情不独自证明人物心理或知情，当前剧本已明确的心理和有意含混仍可保留。

## 条目库：依据情境改写，不逐字套用

下表中的具体动作是可选候选。先确认“场面依据”成立，再根据角色、取景与前后状态增删。例中已有笑意、游移、紧绷或相关物件等初态，也应从本场取得；没有这一初态时换写法，不为了使用条目补造。涉及泪水、伤口、道具接触、点头同意或转身离开时，以当前剧本是否支持为准。

## 写入七列分镜的方法

- 动作描述：写表情的触发、必要变化过程、与正在做的动作或说话的关系。情绪变化跨镜时承接已有状态，不在每次切镜重新“先平静、再变化”。
- 主画面描述：写所选时刻实际可见的神态、视线与姿态。若同时需要几个关键画面，按既有规则交代先后，不能把“笑容正在收回”和“已经恢复平静”当作同刻要求。
- 运镜：仅写实现本场观看机会所需的机位、运动和对焦；不因调用表情库自动推近、升格或另切反应特写。
- 台词：保留原文与发言归属。正在发音时允许相应嘴形；紧抿双唇、咬住嘴角、屏住呼吸等安排在可成立的停顿中。听者可以作无声反应，不因此重复台词或变成说话人。
- 人物提示词：保留身份与造型锚点。临场表情变化不改脸形、眼距、年龄或标志特征，也不把参考肖像的笑容复制到每场。
- 负面提示词：仅按本镜实际需求补充必要限制，例如防止面部身份漂移或错误说话人。不得把本页全部禁则当成负面尾巴。实际用于生成的负面文字若进入 Excel，继续按既定要求加粗红色；正向动作“保持沉默”等不因出现否定字就自动变色。

## 快速回看

沿本镜实际风险核对：有没有依据当前剧本；有没有越过人物／观众知情时点；该景别能否看见；过程与主画面时刻是否相容；口部动作与对白是否冲突；前后镜是否无故重置；是否保持身份与本剧画风。只修受影响处，不新增固定审查表或额外交付列。
