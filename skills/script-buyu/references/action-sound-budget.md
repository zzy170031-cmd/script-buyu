# 动作与声音的预算示例

只在片长、长对白或重叠动作确有预算问题时展开，沿用[DOCX估时](docx-delivery.md)和项目已有记录。写的是观众经历的时间，不是把动作说明念一遍，也不要求每次局修填表。下面数字均为计算示例，不是人物语速或模型能力标准。

## 先后、并行和偏移

顺序发生的段相加。共同起点且全程重叠时取较长者；起点不同时，以各自“开始位置＋持续长度”的最晚结束点算这段跨度。若段从非零起点算，还须减去该段最早开始点；中间的必要空档保留。对白边说边做不自动证明两者完全重叠。

例如一段对白从0秒起估计4.1秒，转门动作在1.6秒起估计6.5秒，两者结束后共同停0.9秒：最后动作在8.1秒结束，共同停顿后是9.0秒。不能把全部长度相加，也不能只取6.5秒再加停顿。这个0.9秒只计一次，环境底声不另加时长。

一次话轮保留它在源稿中的发生位置、说话者、原文和实际声音依据。同一句跨镜只计一次发声；原稿另一次重复照常计入。文字估计标为估算及主要假设；只有实际读演或可靠声音素材支持的相应范围才记实测，文件存在、ASR或有音轨都不证明角色、尾音和同步合格。换了声音或读法，只重核实际受影响预算。

## 音效的事件锚不一定是开头

敲击可对齐撞击，掠过声可能对齐峰值，渐强声可能对齐结束。只有确定了所选声源内部的同步点，才能从事件时点推导铺放范围。令事件时点为E，声源内同步点距开头a，所选完整长度D，则开始为E-a，结束为E-a+D；a和D-a分别包含锚前、锚后声音。

例如计划在8.0秒命中，声音长1.1秒、同步点在声内0.8秒：应从7.2秒铺到8.3秒。若片段只到8.2秒，仍有0.1秒余音冲突；不能按8.0秒开播、直接裁尾，或移动剧情事件来隐藏冲突。真实值要从所选声音测得，未测时保持计划和待核。

前导越过片头、尾音越过切口或片尾时，保留冲突，按批准的停留/切点和后端能力解决。原台词、正常语速及受保护原声不为固定秒数让路；不自行加速、截尾、补静音或定格凑精确片长。

## 预算与执行分开

创作秒码可以表达意图；进入执行时才绑定实际素材版本、PTS/源范围、帧率、保护区和可用后端。采用帧合同的工具以其有理帧率和整数端点为准，不能用漂亮的小数时间戳代替测量。原曲、对白、环境声和静默按当前作品决定，不强制配乐、固定声层数或统一响度处方。

声音卡若只是意图，保留在合同外；当前不支持的跨镜尾音、独立混音和多轨明确列缺口，不能造一条cue或补字段放行。是否可剪需看实际画面并听原声；本页不启动配音、在线TTS或制作。

来源为D024、D036的预算方法及D118、D157的声音边界的独立改写；原文的固定字速、时长、音效淡出和工具性能不作通用规则。见[来源记录](director-knowledge-sources.md)。
