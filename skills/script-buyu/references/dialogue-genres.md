# 全类型台词适用导航

先读[台词核心](dialogue-craft.md)，按需查此页。台词模块服务全类型故事，不锁科幻。以下26类、31条复合路线名称核自当前仓库 [genre-index.json](../data/genre-index.json)，仅是现有检索导航，不是世界上全部题材的封闭分类。示例题材不构成默认风格；未列出的题材也用同一故事—人物—语境原则处理。

下表是我方编辑提问，不是名家观点或每场必检表。只选择实际影响这一场的问题；同一题材可以有完全不同的语气、长短、修辞和叙事态度。

| 现有题材 | 根据具体故事选择的关注点 | 避免固定套路 |
|---|---|---|
| 悬疑 | 谁知道什么，回答暴露还是遮住哪条信息；关系是否影响追问 | 人人说谜语、为了悬念拒答所有常识 |
| 爱情 | 人物怎样靠近、误解、拒绝或重新协商关系 | 全员甜言蜜语、拒绝自动理解成欲拒还迎 |
| 动作 | 当前身体处境、任务、能力与选择代价怎样进入交流 | 全部变成短口令，打斗中强塞人生宣言 |
| 枪战 | 既定空间、识别和协作条件容许什么沟通；谁承担命令后果 | 无来源的精确知情，靠挑衅金句抹掉危险 |
| 科幻 | 设定实际改变了哪些选择、知识与交流条件 | 用术语数量代表科幻感，所有故事都是通信延迟 |
| 惊悚 | 威胁真假、可相信的人和时间压力怎样影响说与不说 | 全员持续喊叫，禁止普通交流或幽默 |
| 喜剧 | 笑来自哪种目标、错位或认真，别人如何接或不接 | 每人负责抖包袱，人物降智无后果 |
| 家庭 | 共同历史、日常分工、亲疏与权力怎样显在小事中 | 只剩和解与温情，所有亲属共用一种腔调 |
| 历史 | 已核时代条件、身份和作品转译约定如何约束表达 | 全员文言、用现代词汇自动判错或自动放行 |
| 战争 | 个体、集体与命令责任如何相互牵制；消息是否可靠 | 宣传口号替代具体人，所有军人同声同气 |
| 奇幻 | 超常规则在此处怎样影响信任、代价或理解 | 借角色背诵完整设定百科 |
| 武侠 | 许诺、恩怨、身份和行动怎样承担“义”的含义 | 人人谈江湖大道理，立誓后没有行动责任 |
| 犯罪 | 利益、法律处境、证据与互信怎样影响说法 | 反派随时自白，所有犯罪故事都像审讯 |
| 青春成长 | 人物有限经验、同伴关系与自我认知怎样变化 | 用幼稚词汇代替年龄，少年替作者总结人生 |
| 恐怖 | 未知如何被命名、误解或拒信；规则何时可以知道 | 全程尖叫、反复解释恐惧直到未知消失 |
| 冒险 | 共同目标、陌生环境与团队分歧怎样进入交流 | 每站同一套插科打诨，行动信息无故重复 |
| 职场 | 权限、利益、专业知识与私下关系怎样改变措辞 | 人人管理黑话，强者永远不解释弱者只能认错 |
| 体育竞技 | 训练、能力、团队关系与赛场压力怎样使话有分量 | 每场靠热血演讲获胜，技术事实随气氛改动 |
| 灾难 | 不完整信息、资源与救助责任怎样影响表达 | 每人轮流煽情，时间紧迫却停下交代全部身世 |
| 神话 | 本作的象征、仪式或日常约定怎样统一人与神的表达 | 神明只能庄严训话，象征自动豁免故事后果 |
| 仙侠玄幻 | 修行规则、师承、欲望和代价怎样影响人物关系 | 等级名称和霸气宣言代替区别，古语自动算高级 |
| 生活治愈 | 陪伴、劳动、闲谈与停留怎样让具体生活可感 | 把伤害轻轻说开便算修复，所有人温柔通透 |
| 音乐歌舞 | 言语与歌唱转换的作品规则，重复怎样产生新含义 | 强制都变生活口语，或每个冲突只靠唱完解决 |
| 西部 | 本作地域、时代、共同体与个人规则怎样相冲 | 人人寡言硬汉，把其他题材只换马和酒馆 |
| 传记人物 | 有据事实、未知私密表达与明确戏剧化如何区分 | 把虚构对白当历史原话，名人每句都成预言 |
| 社会现实 | 具体处境、语言社群、制度与个人选择怎样交织 | 人物代表群体发表立场，刻板方言等于真实 |

现有31条复合路线：宫斗权谋、谍战、末世生存、穿越、重生、系统升级、无限流、甜宠、复仇、校园、医疗、律政、商战、赛博朋克、太空歌剧、超级英雄、古偶仙恋、民俗怪谈、都市、乡村、女性成长、群像、多元亲密关系、推理破案、动作冒险、儿童童话、游戏电竞、机甲、政治社会、年代情感、军事。

这些路线混合了题材、背景、关系、视角和叙事机制，不能都叫互斥的一级题材，也不各生一套台词模板。游戏电竞需按具体游戏核实交互和机制；医疗、律政、历史等关键专业事实需按实际写作需求核源，作者身份不能替代事实核查。

复合故事先明确本剧正在发生什么。例如古装爱情悬疑，在同一场可能先核问证词，再因私人关系换称谓；仍共用同一份事实、知识、承诺与人物选择。不能让“悬疑专家”改信息、“爱情专家”改同意、“古装专家”只负责换古词后直接拼接。由同一统稿职责判断完整场景是否成立。

这份导航覆盖现有索引名称；收录导航不证明实际写作质量，当前原创示例仅展示有限机制。全类型是适用范围与设计要求，不是所有题材已被实际写作验证的结论。
