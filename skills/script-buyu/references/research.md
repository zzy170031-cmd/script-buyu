# 背景与案例检索

检索由当前 Agent 使用实际可用工具执行。读取器与排版器没有自动联网能力。用户明确要求搜索时应执行；用户禁止联网时不能浏览。断网或正文不可访问要记录限制，不能把摘要写成已核实材料。

先列影响剧情的问题，再选来源。真实事件优先当事机构与原始记录；游戏/原作优先官方规则、版本公告；创作方法优先主创原始访谈、工作室流程、行业组织和公开课程。查询只含必要的公开实体或机制，不包含用户未公开的整篇故事、聊天和私人身份资料。

按 [全题材专业支持](genre-professional-support.md) 为当前问题找到相应专业职责与有依据的人物/机构资料。题材作家和导演的创作经验不代替行业事实资格。将采用的专业主张落实为本场允许、不允许或仍待核实的行动条件，再由主笔与统稿决定如何表达；不让顾问替人物选结局。

搜索结果只是线索。打开相关正文，记录来源标题、URL、作者/机构、发布日期（未知则null）、访问时间、适用版本、支持的具体主张、限制及冲突。转载同一来源不算独立证据。官网职员表只能证明履历，不证明某种写作技术。

内部主张分为 user_canon、documented_fact、interpretation、fictional_addition、unverified 或 disputed。虚构对白、动机和合成人物不包装成真实原话或事实。新资料改变核心人物/事件/结局时，先请用户选择如何改编。

参考案例按冲突机制、人物关系、领域规则和篇幅选择，而非按知名度。黄金样板只提供抽象质量检查；反例只能帮助发现错误，未验证样板不能变成已成功的标准答案。不复制其他项目的角色、台词、提示词或资产引用。

项目记录保存在内部工作目录：questions、sources、claims、case_matches、method_uses、decisions、open_questions。每条采用决定可追到来源和受影响的场景/字段。无需把研究流水账或专家名册附在用户 DOCX；只呈现影响理解或确认的必要改编说明。

关键问题得到可用依据、剩余不确定性已明确时停止；可选细节缺失不阻塞所有创作。来源不能核实且会改变主线时，保持未知、提出明确的原创替代或询问用户。
