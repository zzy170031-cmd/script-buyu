# 按场面选用画面与表演

先像导演接一场戏：知道谁把什么递给谁、谁听见了哪句话，再选择拍手、拍脸或留住全景。本页供需要具体写法时选读，不是每镜必读清单；已有文字够用就直接写，库外的相容表达也可使用。例子为新编说明，未验证模型生成效果，不继承其中的人物、道具或画风。

## 先取条件，再选写法

从当前正文和原有连续性记录取本场实际时间、人物知情、物件状态与观看任务。再核候选是否适合本剧媒介、实际场面、可见可听范围、参考用途和输入模式；题材、情绪词与导演姓名只帮助查找，不代替这些条件。

只选能解决本镜需要的内容：接收反应读[表演库](micro-expression-library.md)，照明与材质读[光影库](image-lighting-library.md)，换机位与道具接点读[导演交接](director-handoff.md)。多种方案都相容时直接选一种，不让用户反复选菜单。局部改动沿实际依赖回查；例如照亮袖口可能使后场才揭示的标记提前可见，不能只看相邻镜。只暂停冲突的依赖部分。

| 本场需要 | 可改写的短例 | 使用条件 |
|---|---|---|
| 普通递交要看清归属变化 | 蓝袖人左掌托着木盒递近；灰袖人右掌接稳后，蓝袖左手松开 | 接稳与松手按本场发生；抛接、磁吸、悬浮按既定机制写，不统一要求共同承托 |
| 反打后继续递物 | 开镜时木盒已在灰袖人右掌；蓝袖左手从画面右侧收回 | 自身手别不变，画面位置可换边；不重演已完成的接稳 |
| 眼部被挡仍有交流 | 帘边继续挡住眼睛，她朝画外声音略转头，随后回答原话 | 可用可见口部、头部、手或声音；不补看不见的眉眼，也不把遮眼当成不能接话 |
| 网孔状亮斑用于观看 | 细小亮斑落在面颊与衣领，嘴部仍可辨认 | 只见亮斑不能断言帽子、唯一光源，或材料本体透光/不透光；源稿已定遮挡物则沿用 |
| 暖火与偏冷区域并置 | 烛火靠近的一侧手脸偏暖，后侧区域偏蓝 | 蓝背景不证明蓝灯或月光；相容的画外照明仍可设计，不能借光新增剧情灯具或提前揭示 |
| 窗框组织空间 | 暗窗框围出明亮庭院，前景地面与窗边位置清楚 | 原参考的小人物不自动消失；只借构图不等于首帧已可用于无人戏 |
| 蒸汽、雨、尘确有作用 | 汤碗上方有薄蒸汽，近灯处较亮；端碗时缓缓散开 | 取本场实际或已定设计，静图只写当前状态，动态按需要写变化；不每镜加粒子，不强造扬尘事件 |

## 把参考看见的内容和本场设计接好

一张静帧可以提供手姿、亮暗与遮挡，不能单独证明人物愧疚、已经原谅、认出身份或听见画外话。当前剧本已经明确这些心理与知情时照常保留；含混与不外露也可成立。静帧不能证明运镜、连续动作与声音，但可启发与剧本相容的动态设计，无须等到原片才允许写动作。固定机位也可拍运动，静态环境不必编运动。

同一位图的接触表或多格画面，先按内部位置选实际参考；排版本身不证明先后或同一身份，也不自动变成影片四分屏。剧本授权的漫画分格、多阶段与多重曝光照常使用。窗、屏幕、照片、镜面中的人物分别说明实际可辨认范围；观众能看见不自动等于角色知道。

颜色先写观看关系和本剧方向。用户或任务确需 HEX、色温、比例时核对原件与用途，数字目标不等于模型实现精确控制；黑白、局部色与非写实配色按本剧约定，不把某色固定为某情绪。OCR 漏字不证明画面无字，识别出的“禁止”也不自动成为生成负面；需要读字时查看原图。文件名、片名标签不独自证明出处或真实灯型。

相同字节可复用已核的可见内容观察，路径标签、采用用途和实际上传槽仍逐项核。记录合入现有项目依据，不复制成每镜的来源说明；参考未见的背面、几何及媒体效果保留未知。只有这些未知影响当前决定时才说明，不在所有镜头附未核尾巴。

## 分项写清，再从最终镜行整理复制正文

复杂格可用短标签，例如动作格的“动作／表演”、主画面格的“画面／光影／承接”；标签随内容出现，简单格一句话即可。主画面可以对应关键时刻，不统一当首帧；有多个关键时刻才说明先后，不凑固定三阶段或景别。实际硬切另起镜行，镜内关注转移可留在一镜。

示例条件：二维树洞工坊，蓝袖阿沐把发光种子普通递给赭黄袖阿禾；阿禾右掌已托稳，阿沐左手仍共同承托。反打镜可写：

| 镜号 | 场景 | 人物 | 动作描述 | 主画面描述 | 运镜 | 台词 |
|---|---|---|---|---|---|---|
| B02 | 工坊·同刻·内 | 阿沐、阿禾（仅手） | 阿沐左手松开并收回，种子留在阿禾右掌 | 画面：赭黄袖右掌在画面左侧托种子，蓝袖左手从右侧收回。光影：种子微光落在手缘；背景为二维工坊色块 | 反向斜侧固定近景，承接双方已托稳，不重演递近 | 无 |

同镜复制正文示意：二维色块画风，树洞工坊内，反向斜侧固定手部近景。开镜时赭黄袖阿禾右掌已托稳发光种子，蓝袖阿沐左手仍共同承托。阿沐左手从画面右侧松开收回，种子留在画面左侧的阿禾右掌，微光落在手缘；背景简化，无对白。

这只是文字设计，不保证模型执行手别。具体一致性条件已写进镜行和复制正文；不整段搬入人物目录或旧修订史。实际参考承担外形时可少重复，无实际输入不写“已绑定图1”。有对白时复制正文保留原话、说话者与声道；只有明确的纯画面子任务可另给视觉词，并说明它不含声音。

负面只取当前实际风险，在 Excel 内把负面及标签真实局部红色加粗；正向承接和普通否定对白不误染。本文 Markdown 与复制 TXT 均不证明 Excel 字体完成，最终仍按[交付核验](storyboard-excel.md)重新打开实际表格检查。
