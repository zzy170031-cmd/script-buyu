# 生图光影提示词参考库

v0.1，2026-11-15。用于人物形象提示词、已有剧本的分镜主画面，以及用户已要求的图像光影修改。以下为可改写的创作选项；按需要选读，不要求每张图执行整套维度或固定照明组合。实际生图效果尚未验证。

## 先看这张图要呈现什么

人物参考图通常需要辨认脸形、服装、材质和配色，可从便于辨识的照明起步；本剧明确选择剪影、重阴影或特殊表现时，沿用其用途，未显露的特征不冒称已从图中核验。

剧情画面按当前场面的注意、氛围、人物状态及信息揭示组织光线。照亮何处、保留何处不明，也属于镜头表达；不要求人物每时每刻五官全亮。微表情需要被读清时，结合景别和明暗提供观看机会；有意含蓄、遮蔽或不回应的场面可以照常保留。

同一角色在不同场景可以受不同光色影响，光照变化与固有肤色、衣料颜色、身份设计分别处理。参考图若只用于身份，就不必连它的棚拍光一起复制到夜景。每部剧按已选媒介处理，二维、三渲二或绘画表现不必追求照片般的皮肤与阴影。

## 可选描述维度

选择对当前图有帮助的部分；复杂画面可展开，已有描述足够时不必补满。

| 需要表达什么 | 可以怎样具体描述 | 留给本场的选择 |
| --- | --- | --- |
| 光从哪里来 | 窗口、天空、台灯、招牌，或画外侧前方的柔和照明 | 可用画外光或风格化照明，无须让每盏灯入画；涉及剧情的光源仍依场景。 |
| 方向与照到的部位 | 来自人物左前方的光掠过面颊；窗口侧的袖褶较亮 | 用场景或人物关系表达，避免多个“左侧”指代混乱。 |
| 阴影软硬 | 鼻侧阴影边缘柔和；窗格投影边缘清楚 | 软硬与明暗反差分别选择，柔光也可以保留很深的暗部。 |
| 明暗与观看重点 | 面部亮于背景少许；暗面保留轮廓；主体压暗成剪影 | 是否保留暗部细节由本图用途决定，不默认全亮或全暗。 |
| 光色与整体色调 | 台灯偏暖，窗外环境光较冷；画面整体低饱和 | 光源色、环境反色、物体固有色与整体调色可分别说明，避免把冷暖写成必配套餐。 |
| 材质与落地关系 | 金属边缘有窄高光，布料受光较柔；足底附近有接触阴影 | 根据材质和画风选择；皮肤、衣服、金属不必同样发亮。 |
| 空间与氛围 | 远处明暗更淡，人物与背景通过明暗差分开；薄雾中可见少量光束 | 雾、粒子、镜头耀斑和体积光是可选表现；只在本场或既定风格适用时添加。 |
| 图像修改范围 | 调整脸部受光与相关阴影，保留脸形、服装、构图 | 明确本次改动；移动光源时允许受影响的阴影和反射同步变化。 |

数值只有在用户或当前任务确实需要时使用。色温、光比、灯光角度等可用相对描述；文字数值不代表生成模型已实现物理精确控制。

网孔状亮斑、烛火与偏蓝背景、窗框和色卡的条件化短例见[画面与表演选用](visual-scene-examples.md)，仅按需要读取。可见亮斑不足以确定材料本体透光性，背景偏蓝不独自证明蓝灯；剧本已定或相容的画外照明仍可采用。

## 20 个可改写的场景选项

下面的“写法”都是示例。先看当前场景是否适用，再选择、删减或组合；库外方案也可以直接使用。示例中的窗口、灯具、湿地、雾气及发光物不会自动成为本剧的新道具或事件。

### 人物与自然光

| ID | 场面或用途 | 可选写法 | 可调之处 |
| --- | --- | --- | --- |
| L01 | 便于辨认的人物参考图 | 柔和照明覆盖面部与服装主体，面颊仍有轻微明暗转折，配色容易辨认，背景与人物边缘有适度区别。 | 可用自然光、画外光或简洁棚拍感；背景不限于白色，参考图也不必完全无影。 |
| L02 | 人物需要适量体积感 | 光由侧前方照到额头、鼻梁一侧和面颊，另一侧较暗但仍可辨认，衣领与脸部的明暗关系清楚。 | 可更柔、更硬或更偏侧，照明幅度依人物与媒介。 |
| L03 | 阴天或开阔阴影中的日常场面 | 天空漫射光使脸部过渡平缓，地面与衣物反光较弱，人物与环境保持接近的自然明暗。 | 可保留更明显的暗侧，也可采用平缓表现；不强行补一道耀眼轮廓。 |
| L04 | 晴天直射与清晰形状 | 斜上方日光形成较清楚的投影，受光衣料明亮，背光面保留本场所需的色块或细节。 | 日照方向与影长由已定时间和构图决定，晴天也能表达平静。 |
| L05 | 斜阳中的人物轮廓 | 低斜光从人物后侧掠过发梢和肩部，正面由环境反光维持所需可见度，远处颜色随本场处理。 | 可以保留面部，也可以偏向剪影；暖色和泛光程度均可调整。 |
| L06 | 树荫或窗格的斑驳光 | 少量亮斑落在既有环境和人物衣物上，面部按观看需要保留完整明暗或局部遮蔽。 | 斑驳可密可疏；让它服务动作与情绪，不必额外加雾或光束。 |

### 室内与局部光源

| ID | 场面或用途 | 可选写法 | 可调之处 |
| --- | --- | --- | --- |
| L07 | 窗边交谈或读物 | 窗光从侧面进入，靠窗的脸颊与手背较亮，朝室内的一侧由墙面反光带出少量层次。 | 可保留较深阴影，也可让室内更明亮；窗光不固定代表温柔。 |
| L08 | 明亮室内的柔和环境光 | 较大范围的柔和照明覆盖人物，脸部阴影边缘缓和，背景亮度接近但不抢走本场关注。 | 可平缓，也可收暗一侧；无需指定真实灯具或三点布光。 |
| L09 | 台灯旁的近距离活动 | 台灯的暖光主要落在脸侧、手部与桌面，房间其余部分较暗，纸面反光轻轻托起下颌附近的明度。 | 台灯色彩、环境暗度和照到的范围随本剧选择；不是所有夜读都要橙色。 |
| L10 | 烛火或火光环境 | 既有火光照亮靠近的一侧面部与衣褶，远离光源处逐渐暗下，金属或眼部出现适量反光。 | 单张图描述当前受光状态即可；闪动过程只在需要时进入动作描述。 |
| L11 | 室内外光色相遇 | 室内较暖的照明与窗外偏冷的环境光在人物两侧形成轻微差异，衣服固有配色仍能区分。 | 冷暖可反转、减弱或统一，混光不等于固定蓝橙风格。 |
| L12 | 顶部光形成局部明暗 | 上方照明让额头与肩部较亮，眉骨下方留下阴影，面部其他区域保留符合本场意图的层次。 | 可柔和或强烈；顶光并不自动对应审讯、恐怖或压迫。 |

### 夜景与材质

| ID | 场面或用途 | 可选写法 | 可调之处 |
| --- | --- | --- | --- |
| L13 | 城市招牌或彩色灯光 | 本场既有招牌的颜色映到人物一侧与附近表面，另一侧由环境明度衔接，背景亮点按构图分布。 | 色彩可以克制，也可以浓烈；不把肤色变化误当成角色换肤色设定。 |
| L14 | 低照度夜景 | 以已有天空光或场景光勾出需要辨认的部位，其余区域保留较大暗面，重要动作仍有观看机会。 | 可偏中性、暖或冷；夜景不必通篇蓝色，也不必每张都看清双眼。 |
| L15 | 雨后或已有湿表面 | 湿地映出附近既有光源的亮色，反光随地面纹理分散，人物和墙体保持各自材质反应。 | 反光可淡可强；干燥场面无需为此新增下雨或积水。 |
| L16 | 金属、玻璃与布料并存 | 金属有随形状变化的局部亮边，玻璃保留适量反射与透光，布料高光较缓，彼此不混成同一种质感。 | 依据实际材质和风格简化；动漫可用简洁色块或少量高光代替写实反射。 |

### 观看重点与非写实表现

| ID | 场面或用途 | 可选写法 | 可调之处 |
| --- | --- | --- | --- |
| L17 | 人物与背景需要分开 | 人物靠光的一侧与背景形成明暗差，发梢或衣边只在必要处出现局部亮边。 | 可改用背景亮度、颜色或虚实分离；轮廓光并非必需。 |
| L18 | 有意隐去面部的剪影 | 背景亮于人物，人物主要以轮廓与姿态呈现，面部细节保持在暗面中。 | 可以留下局部反光或保持纯粹剪影，不再同时要求五官全亮。 |
| L19 | 二维或三渲二的明暗设计 | 按当前画风用清楚的受光区与阴影色块概括脸部和衣褶，高光形状与线条语言一致。 | 可采用柔边、硬边或混合处理；既定画风决定程度，不固定成同一种赛璐璐。 |
| L20 | 已有法术、发光道具或装置 | 光色由既有发光对象向邻近脸部、手指和表面扩散，较远区域保持场景原有明暗。 | 依故事和风格决定反光范围；非写实发光也可保持平面化，不凭亮光新增能力。 |

## 写成提示词，而不是堆标签

可从“光源／方向＋受光对象＋明暗或阴影变化＋需要的材质／氛围”组织一句话，也可换顺序或省略不影响理解的部分。关键是画面关系明确，词多不自动代表效果更好。

例如，剧本已经是“夜里，人物在台灯旁读信”，且使用二维动漫画风：

> 台灯从人物右前方照亮脸侧和信纸，背光侧用较深的暖灰色块概括，眉眼仍能辨认；衣料保持柔和明暗，信纸边缘较亮，后方房间稍暗，让注意停在人物与信纸上。

若本镜要隐藏表情，可以改为：

> 台灯主要照亮信纸与手部，人物面部留在暗处，只保留头部轮廓；房间背景维持较暗的色块关系。

两种写法服务不同观看任务，不必统一成一种“正确光影”。选择不能提前显露剧本原本要隐藏的身份、线索或信息。画面为观众提供的可见度也不自动成为角色看见的条件；人物是否认出或发现，仍按本场事实处理。

## 连续性、参考和修改

同一场景跨镜时，承接既定光源的位置与作用，以及已发生的开灯、遮挡和走动。摄影机换边后，光可能从画面左侧变为右侧；不要为了字面上每镜“左侧来光”而让场景光源漂移。人物走入阴影、转头或挡住光时，受光改变可以自然成立。

沿用本剧的视觉方向，单镜仍可改变关注、局部明暗与光线强弱。不同场次的昼夜、空间与情绪可以不同；统一画风不要求所有场景相同光色、反差或亮度。两处光源产生不同投影、彩色灯照到肤色、或有意风格化阴影，都要结合该图判断，不能仅凭“看起来不统一”自动删掉。

修改已有图时，先说清要改的光影和希望保留的身份、姿态、服装与构图。如果调整光源方向，相应阴影和反射通常也要跟随；只改整体调色时则未必需要改阴影方向。避免同时要求“移到另一侧照明”和“所有投影原位不动”，除非用户明确需要该非写实效果。

写入现有提示词时：
- 人物形象提示词：加入适合参考图用途的光影描述，继续保留完整身份、服装、画风与构图。
- 分镜主画面描述：呈现对应时刻的受光、阴影和关注关系；光影随剧情变化的过程按需写入动作描述。
- 运镜：只补与观看或受光变化相关的必要信息；不另加光影列，也不新增交付表。
- 负面提示词：只处理当前实际问题，避免与选定照明互相抵消。平缓光影、深阴影或剪影都可以是有意选择，不能一概放进排除词。实际负面文字进入 Excel 时继续按既定规则加粗红色。

## 只检查影响当前图的冲突

按需要看：描述的光源与投影是否相容；人物和场景是否属于同一种光照关系；需要看清的动作是否可见；刻意隐藏的内容是否仍隐藏；材质是否被无意改成塑料或金属；光色变化是否被误记为人物设计变化。多种方案都成立时直接选择，不把一般光影取舍变成审批，也不要求逐项输出说明。
