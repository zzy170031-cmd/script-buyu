# 多方法统稿一致性演练

2026-09-21。原创微型反例，用于检查方法合并流程，不是用户剧本、金样本或观众效果实验。该示例是草稿阶段授权改写；已确认剧本遇同类问题只报告，取得受影响范围修改授权后再修。

## 冻结输入

原创科幻救援片段。S01：程遥在检修井伤了右腕；程遥负责撤离决定，技师阿岑知道设备状况，女孩小满只知道眼前险情。S02：备用电池只能供一道门，救人门和通往控制室的门不能同时打开。S03：控制室日志才揭示是谁切断通信。当前任何角色都不知道原因。程遥遇事简短下令，阿岑用具体技术事实回答，小满主要用动作反应。允许恐惧、迟疑和成长，不要求人物永远一种语气。

场景意图：用一次有代价的救人选择推进程遥的责任弧线；阿岑提供不可替代的专业判断。另一条地面搜救线可在全篇平行推进，不强迫所有人物围绕程遥。

本剧表达基准：有限知情视角、克制的救援危机语言、通过动作显露责任和代价。悬疑信息服务救援选择，不把本场切成提前破案秀；动作强度来自既定限制，不临时切成无代价的超能力喜剧。允许后续缓和与人物幽默，但须来自脱险后的情绪变化，不能由换用方法卡触发。

## 三项建议拼贴后的失败稿

阿岑一眼看穿内鬼就是队长，挥手替程遥作了决定：“当然救人，控制室算什么！”程遥抡起右手砸开两道门：“小问题，哥可是专业的。”小满也笑：“谁还不是个专业的。”三人穿过两扇门，电池仍亮着。下一场大家第一次读到队长切断通信的日志，惊呼意外。

失败点：①阿岑提前获知无依据的答案，破坏S03揭示；②主角的责任选择由配角代办；③右腕伤势、供电限制和门的阻隔同时消失；④三人共用逞强俏皮话；⑤后续人物再次惊讶与本场已知矛盾。问题不在配角台词多，而在关键因果职能被无意替换。

## 唯一统稿者的取舍

| 建议 | 处理 | 正文结果及理由 |
| --- | --- | --- |
| 技术角色显出专业能力 | 采用 | 阿岑说明只能给一道门供电，保留不可替代的判断；撤离取舍仍由程遥承担 |
| 为爽感立即揭露内鬼 | 弃用 | 没有取得信息的情节支持，泄掉S03的揭示；保留观众疑问 |
| 双门同时破开提高动作强度 | 改造 | 选择救人后控制室方向失去通路，代价可见；爽感来自带着限制完成救援 |
| 人人一句笑话增强节奏 | 弃用 | 此处没有相应人物动机；小满的反应改为行动 |
| 增加伤痛迟疑 | 部分采用 | 用一个扶腕动作延续伤势，不插入病史独白或固定时长 |

## 合并后正文

阿岑把备用电池按进插槽，指示灯只亮起一格。

“只能开一道。救人这边通了，控制室那边就没电。”

程遥看向右侧，通往控制室的门后，通信台的警报断断续续。左侧传来敲门声。

她抬了抬右手，腕上一阵刺痛，便改用左手压住救人门的开关。

“先把人带出去。”

阿岑把供电线切到左侧，门缝一点点展开。小满跪下去，把手伸向门后的人。程遥扶住门沿，直到最后一只手被拉出来。

右侧指示灯熄了。程遥看了一眼黑下去的控制室通道，把未接通的对讲机扣回腰间。

“找另一条路。”

## 依赖追查及结论

| 依赖 | 修复后的状态 | 所需检查 |
| --- | --- | --- |
| 主配角因果职责 | 程遥作救援取舍，阿岑完成供电判断，小满承担救援动作 | 没有用台词份额判断抢戏；每人都有独立贡献 |
| 身体与道具 | 右腕仍伤，左手操作；电池供给救人门，控制室门未开 | 后场若用右腕需有恢复或代偿；电池再次供电必须交代新能源 |
| 知情范围 | 所有人仍不知通信原因 | S03日志仍承担首次揭示功能；不能出现“果然是队长” |
| 路径与后果 | 原控制室通路关闭，需另寻路径 | S03入场必须补足此前已允许的绕行过渡；若授权仅限S02，标出此项并停止修改S03 |
| 人物声音 | 技术事实、简短决定、非语言行动有差异 | 若小满后文主动发言，只需因果成立，不因本场少言而禁止 |
| 节奏与回报 | 险情—明确限制—取舍—获救—失去通路 | 余波服务代价，不为每场强加反转；是否更好看仍需实际作品检验 |

演练修复不是只读这一段：必须检查S01伤势来源、S03首次揭示及到达路径。发现路径依赖后，授权包含S03时可加符合世界规则的绕行过渡；只获S02权限时报告依赖，不能把尚未到达写成已经到达。最终完整性检查覆盖本次交付的全部授权正文，局部修订之外只标问题。

## 反例边界

群像戏可以有同等重要的多线主角、角色接力和视点切换。若创作意图本来就是阿岑承担救援决定，先在获授权的故事设计中明确其弧线，不能用本例主角规则压制他。纯措辞修正只查相关句场；知情、路径、伤势和揭示顺序变化才沿依赖传播。任何方法、学院课程或名家履历都不能自动覆盖用户确认的正文。


## 同一场中的构思转化与可弃用机制

本库原创教学局部，非用户稿、275案例或优胜测试。事实仅为：父亲已联系搬运卖旧琴，读者先知道；女儿不知道卖琴，但认得一个音不准，没有修琴经验。意图是写两人的注意错开，允许父亲回避，不要求他作道德说明。

父亲把搬运人发来的时间记在纸背，翻过去。女儿推开窗，雨刚停。
“这个音还是不对。”她按了一下琴键。
“先把罩子拿来。”
她又按了一遍：“上次老师听出来了，我也听得出。”
父亲伸手，按住琴盖边沿，没有合上。
“能修吗？”她问。
他往窗外看。巷口还没有车，她已经把罩子抱到了琴凳上。

选择与来源：雨停只让她开窗，不强造情绪原因；搬运安排用短叙述，问音/取罩的互动展开，不把全部联系过程成场（OU场景材料的工作迁移）。读者先知卖琴、女儿只谈音，叙述距离没有给她未取得的知识（视点教材与既有信息核心）；识别音准不授修琴能力（既有年龄案例）。“先把罩子拿来”被执行却没回答修琴问题，发言形式与接收分开（Stylistics报告的工作迁移）；“他”在父女连续互动中有锚，不机械点名。父亲仍可回避，作者不让他朗读“发现问题不等于有修复能力”等检核语。

本例不用群唱、竞赛或长期承诺案例：本场没有相应表达任务。可弃用这次回避，若另一稿需要明确答复，直说也合法；不能复制罩子、雨停或末尾等车作为必用收尾。若只是修清指代，不应顺手增添卖琴事实或重排揭示。组合是否改善阅读仍须另稿检验，来源边界见 [本轮继承的研究范围](academic-methods.md#对白与指称的研究范围)。
