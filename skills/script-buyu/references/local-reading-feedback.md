# 按需阅读与写作验证

资料服务于当前中文写作问题，不以逐本读完电子书库作为创作或改造方法的前提。沿用本文件路径以兼容既有入口；不扩展为电子书阅读器或资料采集产品。

## 实际读到了什么

- 可研究用户指定本地材料及获准使用的互联网资料；未公开来稿不上传到搜索或外部服务。优先中文原创正文、连续场景与实际中文交流。外文资料辅助比较方法，不规定中文句式与节奏。
- 围绕问题阅读连续片段，保留来源、版本或访问时间、可回找位置和实际范围；同一作品或访谈的转载不重复计数。目录、摘要和搜索结果只能用于发现，不能冒充正文阅读。
- 只读节选就写“节选”；只有实际覆盖全部可读正文、留有可核查范围并检查缺页乱码，才能称“完整阅读”。无法访问或来源不完整时如实标记，不编造凭证。
- 概括须区分原文事实、创作者本人观点和我方分析。保留适用语境与反例，不复制长篇原文；来源数量和名气不证明写作效果。

## 从资料到可用方法

每批边读边试，按当前问题取少量材料，不等待整库或数量配额才写作。观察可以留在项目研究区；改变默认写法的方法要经过中文成稿对照，见[文本试读](text-review.md)。同时看事实是否保住、人物和回应是否可信、叙述有没有替人物解释过度、原有自然处是否受损。无改善或有退步则不采用，效果不明则保持候选状态。

专业审计按用户实际要求调用，不把固定等级审计设为每次阅读或普通创作的前提。静态审查不能替代成稿效果，模型互评不能冒充用户认可；按已验证的场景采用，不由少量短场推及全书、全季或所有文体。

## 按需调用与发布边界

创作时仅查询当前场景需要且状态清楚的方法，允许不用；保留语体差异，不要求中文一律短促、含蓄或填满语气词。唯一统稿比较取舍，不能为适配来源而改掉已确认故事与人物决定。

完整资料索引、首稿、评审与阅读记录留在项目研究区。Skill仅保留验证后有用的简明方法与必要来源定位，不装入原书、长段摘录或模型日志。本流程不自行上传、同步或发布；交付仍使用原有DOCX与两表Excel接口。

需要核对对白资料层级时，可读[对白中文例证与证据边界](dialogue-source-notes.md)：来源补充可以保留明确标注的研究线索、反例和未证增益结论；它们不因此成为默认写法或已验证方法。
