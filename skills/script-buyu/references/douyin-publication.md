# 抖音项目的发布适配参考

只在本项目明确面向抖音、需要处理观看入口或发布条件时读取。其他平台另查适用材料。以下编辑建议可调整，不作为通用剧本模板；规则核验针对具体发布对象，不给普通文本写作增加成片前置条件。

## 按实际任务分工

主笔和结构职责先处理本集发生什么、观众为何继续看及已有期待如何兑现。首次进入某集的读者缺少哪些必要前提，按 [文本试读](text-review.md) 检查；只补当下理解所需的信息，保留悬疑隐藏、生活停留及人物复杂性。

需要标题、封面文字、开场呈现或合集承接时，可由发布适配编辑提出具体候选。候选说明承诺的看点及其在正文的位置，统稿判断所得与损失。改变时间回指、人物知情、决定、物件或揭示顺序的字幕和旁白，同样属于正文语义变化，按 [连续性](continuity-control.md) 追查后继场面。

游戏、历史或行业只在本场实际涉及的内容上核实。圈外观众需要理解当前利害，熟悉背景的观众需要事实与选择成立；不用每段都加入术语或游戏机制来证明题材身份。外部诊断、打分或提示词可提供疑点，须对照当前稿及相邻场判断，不直接执行整套改法。

开篇危机、小胜利、强对抗、悬念结尾均可成为候选；按实际作品选择，不能从平台名推导固定秒数、反转配额或统一口吻。没有实际成片和观看数据时，只报告文本判断，不预测完播率或保证推荐量。
