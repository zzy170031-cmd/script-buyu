# 按创作取舍读知识

这是随包正文的手动导航，不是另一套生成流程，也不扩大两个 CLI 的检索范围。先看本稿正在写什么；已有正文足够时直接写，不必遍历表格。来源分析与迁移是本库归纳，不能凭目录齐全、案例数或测试通过认定新作品更好。来源与效果边界见[整理说明](method-synthesis-sources.md)。

| 当前选择 | 实际读取入口 | 适用条件与反例风险 |
|---|---|---|
| 动作如何继续，已有办法是否还奏效 | [空间、行动与选择](text-direction.md#空间行动与选择)、[竞赛与队伍](genre-choice-cases.md#竞赛中的办法会被对手与队伍改变) | 当前行动受身体、位置、分工或对方回应影响时，写决定性的条件；不把持续动作写成肢体清单，也不让对手突然全知 |
| 有线索却误判，读者何时理解 | [信息节奏](text-direction.md#信息和文本节奏)、[误判与亲近](genre-choice-cases.md#误判可以带动期待也能承载亲近) | 分开获得材料、解释与传达；事件发生、记录、获取、揭示可以异时，不强制反转或逐轮核验 |
| 奇异能力、危机或维持工作怎样成立 | [奇异能力](genre-choice-cases.md#奇异能力不等于全知或全能) | 能看见不等于能介入；已写持续维护才追查维持条件。约束、代价、反馈不是最低数量要求，纯奇观不补能源系统 |
| 历史、战争、传记怎样进入个人经历 | [个人局部经验](genre-choice-cases.md#从个人局部经验写历史战争与公共任务) | 把时代落实到此人的劳动、资源、等待和可选行动；自述不等于史实，条件解释不免除责任，文学分析不代历史核证 |
| 同一活动或共同证据，是否意味相同理解 | [群体形式](genre-choice-cases.md#同一群体形式里经历可以不同)、[接收对象](dialogue-craft.md#从发言到接收先辨清当前对象) | 共同获知、听懂、同意与行动分开；也允许顺畅沟通和共同快乐，不要求人人隐瞒或每次重复变义 |
| 少年观察、成长与比赛所得怎样具体 | [年龄与成长](writing-choice-cases.md#年龄与成长不把准确观察写成全知)、[能力与结果](genre-choice-cases.md#能力真实有用结果仍可未定) | 经验、观察、技能与另一任务的资格分别看；不套统一儿童腔，不把一次成功写成全面成长 |
| 生活、照料、作品或仪式怎样被接住 | [关心与决定](genre-choice-cases.md#关心与替人决定不必裁成单一性质)、[多年关系](genre-choice-cases.md#多年关系别把一次回应延长成同一承诺)、[作品与仪式](genre-choice-cases.md#作品与仪式由谁接收会改变下一件事) | 只沿本次实际接受的范围写后续；照顾可真诚也可越权，不强造双方有错或强制未圆满结尾 |
| 环境、身体与对白怎样写成同一场事 | [状态与接收](text-direction.md#状态说话与接收)、[情境与接收](dialogue-situation-methods.md#起草时怎样使用) | 影响交流的条件进入动作，也保留闲聊和各自牵挂；不要求每件物品有用、每句错答或每场冲突 |
| 叙述声音、感知与描写分量怎样协调 | [信息、声音与距离](story-craft.md#选择叙述的信息声音与距离)、[叙述选择](writing-choice-cases.md#展开概述和评论由谁承担) | 分开叙述语言、人物注意与知情；诗性、停留可有自身价值，不把身体征象变成唯一心理解释，不用“可拍”抹掉约定文体 |
| 声音或时间含混是否真的妨碍理解 | [声音知情](text-direction.md#声音事件与知情)、[信息与时间](text-direction.md#信息和文本节奏) | 分清配乐、环境声和听觉静默，准备、开始与完成；只补当前必要关系，不要求报全时序或新增事实 |
| 改对白、删句或删整场，怎样处理得失 | [修订尺度](text-review.md#按症状选择修订尺度)、[沿角色回读](dialogue-craft.md#从局部修辞复核到整剧) | 实际连读剩余正文，确认后续依赖仍在；更紧凑可能少生活温度，更清楚可能更解释腔，不把局部修复升为总则 |
| 转成文字分镜后，新增了什么 | [转译的所得](storyboard-excel.md#判断转译的所得) | 分开源稿已有表达与转译新增的观看安排；技术清楚和阅读负担可同时增加，未成片就不声称成片效果 |

## 候选与未纳入项

跨形式的并置、共同证据中的不同接收、导演声音观念等，可以帮助提出问题，但局部来源分析和试写不证明稳定收益。已有章节足以表达的认识继续用原入口；尚缺独立复核或适用性验证的具体案例不作示范稿，也不要求用户再读研究原件。

不把新方法变成配额：每次重复不必变义，每场不必升级冲突，能力不必同时展示约束、代价、反馈。真正采用后，只沿本轮改动回读当前正文与受影响承接，允许保留原稿。下一项比较研究的设想不算已执行结果。
